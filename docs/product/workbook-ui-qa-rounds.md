# 워크북 버튼 개선 독립 검수 기록

## 2026년 10월 26일 첫 검수

대상은 [개선 계획](workbook-ui-review-cycle.md)의 첫 묶음 B01~B06·B10이다. 구현 세션 `워크북 작업 이어가기`의 변경을 별도 브라우저 탭에서 직접 조작했다. PC 1280×720, 모바일 390×844·320×740을 사용했다. 구현 담당자의 자동 검사 결과는 단위 115건, 대상 E2E 8건, 회귀 E2E 50건 통과 로그로 확인했다. 이 수치는 독립 QA가 다시 실행한 검사 수가 아니다.

1-4 기본·중간·최종을 PC에서, 기본·중간·최종을 모바일 폭을 오가며 확인했다. 1-1은 PC 기본·중간·최종과 모바일 최종을 확인했다. 2-2는 PC 기본·중간·전체와 모바일 전체·접기를 확인했다. 세 수업의 모든 상태를 모든 폭에서 전수 확인한 것으로 표시하지 않는다. 나머지 상태와 원문 편집 보존 확인은 다음 검수에서 이어간다.

## 구현 세션에 전달한 수정

2-2 화면 2, PC 1280×720에서 ‘전체 연결 보기’를 누르면 왼쪽에는 현재 한 항목의 출처 카드 약 82px만 남고, 오른쪽에는 네 항목 전체 카드 약 423px가 나온다. 본문 폭 736px 중 전체 원문은 362px만 쓰며 왼쪽 아래가 크게 빈다. 전체 연결이 길게 늘어나 조작과 편집 영역을 더 아래로 밀어낸다.

전체 보기에서는 단일 출처 카드를 제거하고 전체 연결이 본문 폭을 사용하도록 요청했다. 한 항목 보기의 2열과 모바일 원문 중심 구성은 유지한다. 전체 → 한 부분 → 전체 왕복과 390px·320px 편집 접근을 재검수한다. 기존 완료 판정과 입력·기록 변경은 요구하지 않았다. 구현 세션에 수정 요청과 근거를 전달했으며 반영을 기다린다.

증거: [2-2 PC 전체 연결](../design-references/workbook-button-qa/bridge-final-desktop.png), [1-4 PC 최종](../design-references/workbook-button-qa/prompt-final-desktop.png), [1-4 320px 최종](../design-references/workbook-button-qa/prompt-final-mobile320.png), [2-2 320px 전체 연결 하단](../design-references/workbook-button-qa/bridge-final-mobile320.png).

이번 판정은 버튼과 여백에 대한 제품 검수이며 실제 입문자 참여 평가나 실제 휴대폰 키보드 검증은 아니다. 전체 묶음의 최종 통과는 수정 반영과 남은 독립 검수 후 판정한다.

## 2026년 10월 26일 수정 후 최종 판정

**첫 묶음 B01~B06·B10은 통과다.** 실행·선택·보조 조작·수업 이동이 구별되고, 이전에 지적한 전체 연결의 빈 공간도 수정됐다. 다른 단원 확대는 이번 판정에 포함하지 않는다.

2-2 PC 전체 연결에서 단일 출처 열이 사라지고 네 항목 원문이 본문 전체 폭으로 나오는 것을 직접 확인했다. 전체 → 한 부분 → 전체를 키보드로 왕복했으며 한 부분에서는 기존 PC 두 열이 복원됐다. 모바일 390px 기본 선택과 320px 다른 항목 선택·전체 펼침·직접 편집 접근을 확인했다. 직접 편집한 원문에 일치 항목이 없을 때 안내를 표시하고, 항목 선택과 전체 펼침을 반복해도 원문을 바꾸지 않으며 다음 버튼도 기존처럼 활성화됨을 확인했다.

1-1은 추가로 320px·390px 기본·중간·최종을 확인했다. 최종 연결 후 첫 메모 선택에 포커스가 옮겨지고 Tab으로 다음 선택에 접근한다. 선택과 전체 펼침이 수업 진행의 새 필수 조건이 되지 않았고 다음 버튼은 활성 상태를 유지했다. 1-4의 기본·중간·최종 PC와 모바일 관찰은 첫 검수의 증거를 재사용한다. 모든 상태와 모든 크기의 27개 조합을 독립 QA가 전수 확인한 것으로 주장하지 않는다. 구현 담당자의 27개 조합 캡처와 관련 E2E 결과를 함께 근거로 사용한다.

수정 후 구현 제출의 `check-final.log`와 `progressive-final.log`는 각각 단위 115건과 대상 E2E 8경로 통과를 기록한다. 공통 이동·3~5단원 영향은 앞선 회귀 50경로와 구현 담당자의 실제 화면 기록을 근거로 판단했다. 새 완료 조건을 추가하거나 기록 로직을 바꾼 증거는 없다. 전체 서비스·실제 외부 실습 완료까지 검증한 것은 아니다.

수정 후 증거: [2-2 전체 폭](../design-references/workbook-button-qa/bridge-fixed-desktop.png), [1-1 모바일 선택과 포커스](../design-references/workbook-button-qa/ai-final-mobile390.png). 앞 절의 `bridge-final-desktop.png`는 수정 전 결함 근거로 유지한다.

구현 세션에 통과 판정을 전달하고 이번 첫 묶음의 자동 후속 확인을 종료한다. 커밋·배포는 하지 않았다. 이후 사용자의 실제 화면 피드백이나 새 재현 문제가 생기면 해당 항목에서 검수를 재개한다.
