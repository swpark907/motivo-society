# 03 코드 에이전트 준비하기

2026-10-06. 카피바라 맵의 실습 쉼터 수업 초안. 사용자 정정으로 이전 ChatGPT 웹 채팅 준비 원고를 교체했다. Windows와 Mac 모두 지원하며 개인 컴퓨터의 데스크톱 앱에서 실습한다. 공식 문서 확인과 실제 설치·계정별 실행 검증은 구분한다. 원고를 4개 학습 묶음으로 조정해 프로토타입에 반영했다. OS별 신규 설치와 학습자 계정 조건의 실제 검증은 남아 있다.

## 비교와 기본 안내 선정

| 도구                 | 데스크톱 실습 방식                                          | 입문에서 설명할 차이                                        |
| -------------------- | ----------------------------------------------------------- | ----------------------------------------------------------- |
| Codex 데스크톱       | 로컬 프로젝트 폴더를 연결하고 파일 작업을 요청              | 로컬 작업과 클라우드 작업의 구분, 프로젝트 선택과 변경 확인 |
| Cursor Agent         | 데스크톱 편집기에서 폴더를 열고 Agent로 파일 수정·명령 실행 | 편집기 화면과 Agent 패널의 관계                             |
| Claude 데스크톱 Code | 데스크톱 앱의 Code에서 프로젝트 폴더를 선택하고 작업        | 일반 Chat과 Code의 구분, Code 사용 가능한 계정 조건         |

공식 자료상 세 후보 모두 Windows·Mac 데스크톱 경로를 제공한다. **기본 안내는 Codex 데스크톱**으로 선정한다. 현재 이 프로젝트를 실제로 만드는 환경이라 예시와 확인 과정을 같은 도구에서 준비하기 쉽다는 교육 설계 판단이다. 초보에게 더 쉽거나 성능이 우수하다는 비교 실험 결과는 아니다. 공식 OpenAI 문서는 현재 배포 앱을 ChatGPT desktop app으로 표기하고 Codex 작업 선택을 안내하므로, 공개 원고의 앱 이름과 다운로드 화면은 실제 배포본을 대조한다.

이미 Cursor Agent나 Claude Code 데스크톱을 사용할 수 있는 사람은 공통 작업을 해당 환경에서 진행할 수 있다. ChatGPT·Claude·Gemini의 일반 웹 채팅만 준비한 상태는 로컬 코드 에이전트 준비와 같지 않다.

설치 가능 여부와 에이전트 이용 가능 여부는 다르다. Claude 공식 안내는 Code 인증 문제 점검에 유료 구독 확인을 포함한다. Codex·Cursor도 학습자 계정에서 사용 가능한 기능과 한도를 확인해야 한다. 유료 플랜을 임의로 필수 구매로 정하지 않으며, 모두 무료로 수료 가능하다고 약속하지 않는다. 요금·계정 조건은 실제 수업 공개 전에 확인해 명시한다.

## 공통 학습 흐름

**작업 폴더 선택 → 할 일 요청 → 파일 변경 확인 → 실행해서 결과 확인 → 수정 요청**

도구가 바뀌어도 이 작업 흐름을 적용할 수 있다. 화면·버튼·권한·제공 기능은 다를 수 있다. 파일을 직접 바꾸는 도구이므로 현재 작업 폴더와 요청 범위를 확인하는 것이 대화 입력만큼 중요하다.

## 화면 1 — 만들 일을 도와줄 앱 (3단계)

2강의 구분을 실제 화면에서 다시 확인한다: 웹/데스크톱은 접속 방식이며, LLM은 모델·에이전트는 도구를 사용해 작업을 이어가는 시스템이다. 앱 실행 후 일반 채팅인지 코드 에이전트인지, 실습 폴더가 연결됐는지를 학습자가 직접 확인한다. 설치 완료만으로 준비 완료를 기록하지 않는다.

1. 카피바라: “답을 읽는 데서 한 걸음 더 가서, 내 컴퓨터에 홈페이지 파일을 함께 만들고 싶어.” 코드 에이전트는 요청에 따라 프로젝트 파일을 읽고 만들거나 고치고, 실행해서 확인하는 일을 도와줘요. 실제 가능한 작업은 도구와 허용한 범위에 따라 달라요.
2. 이 클래스에서는 데스크톱 앱을 사용해요. 앱은 내 컴퓨터에서 실행하는 프로그램이고, 작업 폴더는 만들 파일을 모아두는 공간이에요. 웹 채팅에서 코드 설명을 받는 경험과 파일을 직접 만드는 경험을 구분해요.
3. 기본 안내는 Codex예요. 이미 Cursor Agent나 Claude Code를 사용할 수 있다면 익숙한 도구로 같은 작업을 해도 좋아요. 여러 앱을 모두 설치할 필요는 없어요.

## 화면 2 — 앱과 실습 폴더 준비 (3단계)

### 1. 내 컴퓨터에 맞게 설치

공식 다운로드 안내에서 Windows 또는 Mac용 데스크톱 앱을 받아요. Windows는 공식 다운로드 링크의 Microsoft Store 안내를 따라 설치해요. Mac 공식 앱 페이지는 Apple Silicon용 다운로드를 표시하므로 내 칩과 지원 조건을 확인한 뒤 설치해요. 정확한 설치 파일 이름·지원 OS 최소 버전·프로세서 선택은 실제 다운로드 화면 확인 후 안내를 확정해요.

[Codex 데스크톱 시작 안내](https://learn.chatgpt.com/docs/quickstart) · [Cursor 시작 안내](https://cursor.com/docs/get-started/quickstart) · [Claude Code 데스크톱 안내](https://code.claude.com/docs/en/desktop)

설치 후 앱을 실행하고 계정에 접속해요. 계정에서 코드 에이전트를 사용할 수 있는지도 확인해요. 일반 채팅 화면이 열린 것만으로 준비가 끝난 것은 아니에요.

### 2. 실습 폴더 연결

컴퓨터에서 찾기 쉬운 곳에 빈 폴더 `my-first-web`을 만들어요. 폴더는 관련 파일을 모아두는 공간이에요. 이번 수업의 작업은 여기에 모아요.

앱의 로컬 프로젝트·폴더 열기 기능으로 이 폴더를 연결해요. ‘로컬’은 지금 사용하는 컴퓨터에서 작업한다는 뜻이에요. Codex에서는 Codex 작업과 로컬 환경을 선택하고, 연결된 폴더가 `my-first-web`인지 확인해요. Cursor는 폴더를 열고 Agent를, Claude는 Code에서 프로젝트 폴더를 선택해요.

문서함 전체나 다른 작업 폴더를 선택할 필요는 없어요. 수업에서 만든 빈 폴더를 선택해요.

### 3. 요청할 자리 찾기

작업 요청 입력창과 작업을 멈추는 조작을 찾아봐요. 요청을 보내기 전에 현재 프로젝트가 실습 폴더인지 다시 확인해요. 파일 변경과 명령 실행에 대한 허용 여부를 물으면 작업 내용과 범위를 읽어요.

지금은 실제 제작 요청을 보내지 않아요. 다음 수업에서 작은 요청을 보내고 결과를 확인해요. 복잡한 웹 개발 도구 설치는 첫 결과물을 만들 때 필요한 범위에서 별도로 안내해요.

## 화면 3 — 준비 확인과 정리

확인 문제: 다른 코드 에이전트로 바꾸어도 이어서 적용할 수 있는 것은 무엇일까요?

1. 버튼의 정확한 위치와 모든 이용 조건
2. 작업 폴더를 정하고 요청한 뒤 파일과 실행 결과를 확인하는 흐름 **(정답)**
3. 일반 웹 채팅 로그인만으로 프로젝트 파일이 수정된다는 기대

정답 이유: 화면은 달라도 작업 공간을 정하고, 변경과 실제 결과를 확인하고, 수정 요청으로 이어가는 흐름은 적용할 수 있어요.

오답 이유: 앱과 계정마다 기능·화면·권한이 달라요. 파일 작업이 가능한 환경에서 실제 변경과 결과를 확인해요.

컴퓨터 준비 상태는 확인 문제와 분리한다:

- 앱에서 코드 에이전트를 사용할 수 있고 실습 폴더까지 연결함: **컴퓨터 준비 확인**. 학습자 본인의 확인이며 자동 검사 결과가 아니다.
- 설치·로그인·사용 권한·폴더 연결 중 막힘: **준비 필요**. 막힌 단계의 공식 안내를 확인한다.
- 모바일로 설명·문제를 읽음: **복습 확인 · 컴퓨터 준비 필요**.

카피바라: “함께 만들 자리를 준비했어. 다음에는 작은 요청을 보내고 무엇이 달라졌는지 확인해보자.” 같은 마을의 다음 장소로 돌아간다. 4수업은 에이전트 입력창에서의 첫 대화·작업 확인을 기준으로 다시 설계하고, 5수업에서 에이전트와 바이브코딩을 정리한다. 첫 파일 활동의 구체 범위는 후속 원고에서 정한다.

## 프로토타입 반영 — 2026-10-06

사용자 요청으로 03 실습 쉼터를 02 완료 뒤 열도록 연결했다. 준비할 앱·학습 환경 선택 → OS별 설치·계정 안내 → 실습 폴더 연결 → 확인 문제와 준비 상태의 4개 화면 묶음이다. 설명 묶음은 각각 3단계로 교체한다. 핵심 행동·용어는 굵게 강조한다. 컴퓨터 준비 모드는 앱 이용·로컬 폴더 연결·입력창/중지 조작을 모두 본인이 확인한 뒤 준비 확인을 선택한다. 미준비는 설명 확인, 모바일 복습은 복습 확인으로 기록하며 이 둘은 컴퓨터 준비 확인으로 처리하지 않는다. 기록은 현재 방문에만 유지되고 외부 앱을 자동 검사하지 않는다. 04 첫 대화는 계속 준비 중이다.

## Q11 공식 지원 조건 감사 — 2026-10-13

이전 실행의 조회·수정 결과를 회수하고 원문을 대조했다. 확인일은 **2026-10-13**이며 아래 페이지의 발행/수정일은 조회 본문에서 확인되지 않아 추정하지 않는다. 공식 지원 안내 확인과 실제 설치 성공은 별개다.

- [OpenAI 앱](https://learn.chatgpt.com/docs/app): ChatGPT desktop app 명칭과 Mac Apple Silicon 다운로드 표기. Windows 설치 파일 일반 표현과 Mac 칩 누락을 최소 수정했다. Intel Mac 지원·최소 OS 버전을 임의로 확정하지 않는다.
- [Windows 앱](https://learn.chatgpt.com/docs/windows/windows-app): 공식 다운로드는 Microsoft 배포 링크이며 msstore 설치 경로를 안내한다. 네이티브 Windows 작업을 지원하고 WSL 설치를 수업 필수로 추가하지 않았다.
- [작업 환경](https://learn.chatgpt.com/docs/environments/modes)·[프로젝트](https://learn.chatgpt.com/docs/projects): 로컬 작업/폴더 연결 흐름 유지. 현재 공개 UI의 로컬 안내를 클라우드 작업으로 바꾸지 않았다.
- [OpenAI 요금](https://learn.chatgpt.com/docs/pricing): 무료 플랜의 데스크톱 이용은 적용 상태와 기능·모델·한도 조건이 있다. 모두 무료 수료 가능 또는 유료 필수라고 약속하지 않는다.
- [Cursor 시작](https://cursor.com/docs/get-started/quickstart)·[요금](https://cursor.com/pricing): 기존 대체 도구 유지. 무료 Agent 요청 제한과 모델별 추가 비용 확인 문구를 보강했다.
- [Claude 데스크톱](https://code.claude.com/docs/en/desktop): 기존 Code 경로 유지. 인증 문제 안내의 Pro·Max·Team·Enterprise 활성 유료 구독 확인 조건을 보강했다. 개인 계정 이용 가능 여부를 대신 확인하지 않았다.

구조·진행 상태·본인 준비 체크·완료/해금 조건은 유지했다. 실제 Windows 설치, Mac 신규 설치, 학습자 계정의 사용량·권한, 실제 index.html 생성/수정/실행은 여전히 미검증이다. 설치·새 계정·구독·결제는 실행하지 않았다.
