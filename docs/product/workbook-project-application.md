# 자기 프로젝트 적용 기록 — 2026-10-08

전체 클래스 완료 감사에서 끊긴 ‘예시 학습 → 자기 프로젝트 적용 결과’ 연결의 작은 단위다. 네 제작 단원의 마지막 화면에 기존 입력·선택 스타일을 재사용한다. 독립 지도나 외부 서비스는 만들지 않는다.

## 이번 범위와 완료 기준

- 기획과 첫 제작, 화면과 사용 경험, 동작과 데이터, 공개와 운영의 예시 완료와 자기 프로젝트 적용 기록을 분리한다. 기존 예시 완료·다음 단원 조건은 유지한다.
- 처음에는 ‘적용 여부 미기록’이다. 학습자가 ‘아직 직접 적용하지 않았어요’ 또는 ‘내 파일에 적용한 결과 적기’를 고른다. 모바일에서 기록을 작성하는 것만으로 실습 완료가 되지 않는다.
- 자신의 목적·독자·제목·소개·내용과 단원의 확인 행동으로 실습 요청 초안을 만든다. 초안은 편집 가능하며 AI에 자동 전송하지 않는다.
- 결과·문제 유무·재확인 근거를 적은 뒤 본인 확인 버튼을 눌러야 ‘직접 적용·확인 · 본인 기록’이 된다. 미해결 문제가 있어도 확인한 사실을 남길 수 있으므로 문제 해결 성공 인증이 아니다.
- 기록 내용 변경은 확인 전으로 돌린다. 같은 모드·확인 버튼 반복 클릭, 취소·이전·완료 재방문·이야기 왕복에는 기록을 유지한다. 기획의 제목·독자·목적·소개·내용 변경은 네 적용 기록을 초기화한다.
- 지도에서 네 기록을 펼쳐 다시 읽는다. 파일명/주소는 선택 텍스트이며 링크로 만들거나 외부 방문·업로드·배포를 실행하지 않는다. 비밀 정보는 적지 않도록 안내한다.
- 워크북 레이아웃의 React 방문 메모리만 쓴다. 새로고침 초기화는 합의된 경계이며 localStorage·회원별 서버 저장·DB/API를 추가하지 않는다.
