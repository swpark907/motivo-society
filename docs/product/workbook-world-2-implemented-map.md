# 화면과 사용 경험 독립 지도 — 2026-10-09

최신 마을 지도 구별 적용과 실제 두 폭 검수는 [자산 매핑 문서](workbook-village-map-assets.md)를 따른다. 사용자 후속 직접 승인으로 새 강·정원·돌다리 자산1장을 생성하고 기존 세 단계와 지형에 맞는 좌표·동선을 연결했다. 아래 새 아트 없이 같은 원화·동일 좌표를 재사용한 기록은 당시 이력이다.

사용자의 직접 승인으로 기존 화면 단원 세 단계와 별도 지도를 연결한다. 첫 제작의 제목·독자·목적·소개·내용을 이어 쓰며 기존 원화·마커·캐릭터·스타일을 재사용한다. 새 아트·다른 월드·외부 파일 작업을 추가하지 않는다.

| 학습 지점             | 기존 활동                                             | 다음 지점 조건                  |
| --------------------- | ----------------------------------------------------- | ------------------------------- |
| 두 화면에서 문제 찾기 | 휴대폰·넓은 화면 비교와 불편한 한 가지 기록           | 두 화면 확인과 관찰 기록        |
| 개선 요청 쓰기        | 페이지 너비 한 부분을 고치는 요청 생성·편집           | 관찰 조건과 비어 있지 않은 요청 |
| 수정 전후 확인        | 두 폭·같은 내용/버튼 비교, 예시와 본인 적용 기록 구분 | 기존 비교 기록과 완료 조건      |

`WorkbookProgressContext`의 `experienceStop`을 수업 단계와 지도 위치가 공유한다. `src/lib/workbook-experience.ts`의 선행 판단을 지도·진입·다음 버튼이 함께 사용한다. 지도 선택과 마지막 단계는 이야기·목록·브라우저 왕복 중 유지한다. 전체 단원 다시보기도 마지막 단계를 이어 열고, 처음부터 다시 읽으려면 첫 지점을 선택한다. 기획 변경은 기존 후속 기록과 이 월드 위치를 초기화한다. 요청을 지우면 마지막 지점이 다시 잠기며 확인 기록을 무효화한다.

완료 표시와 본인 외부 파일 확인은 별개다. 예시 화면의 CSS 비교는 실제 파일 수정 성공 인증이 아니다. 회원 저장·localStorage·DB/API·배포를 연결하지 않는다. 같은 방문에서만 상태를 보존하며 새로고침 초기화는 허용한다.

두 제작 지도에서 캐릭터 위치만 `--space-4`만큼 올려 현재 지점 체크 표시와 접지선을 분리한다. 마커 좌표·경로·공통 AI 지도는 유지한다. 위쪽 두 미사용 건물과 월드마다 같은 배경을 재사용한 한계는 남는다.
