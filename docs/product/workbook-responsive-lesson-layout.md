# 워크북 수업 화면 반응형 기준

2026-10-29 · 짧은 설명과 인트로는 일반적인 화면에서 한 장면의 내용과 이동 조작을 함께 보여준다. 학습자가 스크롤 위치를 찾기보다 장면의 내용을 읽고 다음으로 넘기는 데 집중하도록 한다.

## 설계 원칙

- 화면 전체 높이가 아니라 GNB, 워크북 메뉴, 수업의 상단 안내와 하단 이동 영역을 제외한 **실제 본문 높이**를 기준으로 한다.
- 장면이 넘치면 먼저 불필요한 여백과 장식, 그림·도식 크기를 조정하고 작은 화면에는 내용을 재배치한다. 전달할 내용이 여전히 많다면 장면을 나눈다. 본문을 무리하게 축소하거나 잘라내지 않는다.
- 이전·다음 등 필수 조작은 화면 안에 유지한다. 모바일 안전 영역, 키보드 포커스와 터치 영역을 고려한다. 사용자가 장면을 바꾸면 새 본문은 맨 위에서 시작한다.
- 작은 창, 가로 모드, 브라우저 확대, 글자 크기 변경이나 추가 콘텐츠가 있을 때는 본문 스크롤을 안전장치로 유지한다. 입력·기록·선택적으로 펼치는 긴 콘텐츠도 스크롤을 허용한다.
- 색상만으로 현재 장면을 나타내지 않고, 장면 이동에 자동 재생을 적용하지 않는다. 모션 줄이기 설정에서는 장면 표시 전환 효과를 제거한다.

## 확인 기준

새로운 짧은 수업 장면은 내용이 달라지면 모든 장면을 직접 점검한다. 아래 크기는 검수 출발점이며 모든 기기에 대해 스크롤이 없다는 보장은 아니다.

- PC 1280×720, 모바일 390×844, 낮은 모바일 375×667: 본문과 이동 버튼이 보이는지, 읽을 내용이 가려지지 않는지 확인한다.
- 320×480 등 매우 작은 화면과 브라우저 확대·큰 글자: 본문 스크롤로 끝까지 읽고 하단 조작에 접근할 수 있는지 확인한다.
- 장면 이동 후 스크롤 위치, 키보드 포커스, 모션 줄이기, 가로 넘침 및 모바일 안전 영역을 확인한다. 실제 텍스트·도식·버튼으로 검수하고 빈 상자 높이만 맞춰 완료로 보지 않는다.

## 현재 적용 범위

1-1-1 인트로는 `WorkbookClassIntro`의 내장 수업 레이아웃에 반영한다. `embedded`에서 본문은 남은 높이를 사용하며 넘치면 스크롤하고 이동 영역은 별도로 유지한다. 기존 수업 전체를 자동으로 변경하지 않으며, 후속 화면을 만들거나 수정할 때 이 기준을 적용한다.
