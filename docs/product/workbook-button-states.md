# 버튼 배경 피드백과 최소 테두리

2026-10-27. 사용자의 기본 디자인 방향에 따라 강의 공통·표지 버튼의 빠진 배경색 호버 피드백을 보완하고 장식 테두리를 줄였다. 지도 그래픽·작업실 같은 별도 경험을 일괄 재디자인한 작업은 아니다.

| 용도                            | 기본 표현                       | 마우스 호버                   |
| ------------------------------- | ------------------------------- | ----------------------------- |
| 주 실행                         | 오렌지 채움                     | 같은 계열에서 밝아짐          |
| 이전·다음 이동, 보조 조작, 헤더 | 투명 또는 중립 면               | 중립색 배경                   |
| 항목 선택                       | 선택 면·체크·밑줄               | 중립색 배경, 선택 표시는 유지 |
| 정답·오답                       | 기존 초록·빨강 면과 정오답 표시 | 의미 색을 유지하며 밝아짐     |
| 밝은 표지 시작                  | 민트 면                         | 짙어진 민트                   |
| 비활성                          | 기존 비활성 표현                | 변화 없음                     |

`src/styles/_mixins.scss`의 `workbook-button-feedback`은 마우스 호버 환경에서만 120ms 배경색 전환을 적용한다. disabled·aria-disabled는 제외하고 모션 줄이기에서는 전환을 제거한다. 색은 각 역할의 의미 변수로 제공한다. 강의·상호작용·표지·클래스 공통 SCSS를 수정했고 제품 로직은 수정하지 않았다. 최소 터치 높이 44px, 키보드 포커스 링, 탭의 현재 위치 선, 라디오 선택 표시처럼 기능을 전달하는 선은 보존했다.

## 검수

- `pnpm check`: 최종 보조 버튼 색 변수 보정 이후에도 33개 파일·115개 테스트 통과 (`check-final.log`).
- 기존 E2E PC·모바일 **76경로 통과**. 17수업과 표지 왕복, 전체 예시 학습, 기획·요청 원문, 퀴즈·저장·이동 조건을 포함한다.
- 실제 호버 시각 비교는 임시 Playwright 캡처로 보완했다. 역할별 normal/hover 화면과 계산된 배경색을 기록했으며 비활성 버튼은 전환이 끝난 상태에서 배경이 동일함을 확인했다. 스타일을 고정하는 테스트는 저장소에 추가하지 않았다.
- CUA로 PC 1280×720·모바일 390×844·320×740에서 선택 면·체크·밑줄과 포커스 링을 직접 확인하고 Tab·Enter·Space로 조작했다.
- 자체 코드 검토에서 비활성·모션 줄이기 예외, 선택·정오답 의미 색, 보조 조작과 주 실행의 색 구분을 확인했다. hover에서 크기나 위치를 바꾸지 않아 배치가 흔들리지 않는다.

캡처: [버튼 상태 폴더](../design-references/workbook-button-states-20261027/). `cover-start`, `lesson-primary`, `lesson-support`, `lesson-next`, `lesson-header`, `lesson-selected`, `lesson-disabled`, `lesson-incorrect`의 normal/hover 쌍이다. `selection-focus-*`는 직접 조작한 PC·모바일 화면이다. 자동 호버 캡처와 직접 키보드·모바일 검수를 구분한다.

실행 로그와 계산된 상태 기록은 `/private/tmp/workbook-button-states-20261027/`에 있다. 기존 로컬 변경을 유지했으며 커밋·배포는 하지 않았다.
