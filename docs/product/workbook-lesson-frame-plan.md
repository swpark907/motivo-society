# 인트로 위치와 수업 공통 레이아웃 전환 계획

2026-10-30 · 사용자 결정과 실행 계획. 실행은 사용자 확인 후 단계별로 진행한다.

## 결정한 것

- **인트로 위치:** 클래스 오리엔테이션으로 올린다. 처음 "강의 시작하기"를 누르면 바로 인트로(4장면)가 나온다. 이후 방문의 "학습으로 돌아가기"는 인트로를 건너뛴다. 인트로는 지도에서 "인트로 다시 보기"로 다시 볼 수 있다.
- **인트로 다음:** "첫 수업 시작"은 1-1 수업으로 바로 간다. 지도는 1-1을 마치고 "단원 지도로" 나올 때 처음 본다.
- **예시 화면:** 강의 시작 직후의 "배우고 나면 이런 페이지를 만들 수 있어요" 화면은 시작 흐름에서 뺀다. 인트로 2장면과 역할이 겹치기 때문이다. 클래스 소개 페이지의 제작 예시 영역은 유지한다.
- **1-1 표지:** 인트로가 빠진 자리에 다른 수업과 같은 강의 시작 표지를 쓴다. 문구는 `workbook-lesson-covers.ts`의 `ai-understanding`에 이미 있다.
- **수업 공통 레이아웃:** 인트로의 틀을 공식 레이아웃으로 쓴다. 수업 안의 오른쪽 패널은 폐기한다. 하단에 ← 이전 · 단계 점 · 다음 →를 둔다. 1단원 5개 수업을 먼저 옮겨 확인을 받은 뒤 나머지 13개를 옮긴다.

## 오른쪽 패널에 있던 것과 옮길 곳 (제안 기본값)

현재 패널이 있는 수업은 18개다(조사 결과는 이 문서 작성 세션에서 정리). 16개는 같은 구조다. 구조가 다른 것은 선택 심화(Practical)와 이어갈 작업(Review) 두 개다.

| 패널 요소                                                                       | 옮길 곳                                                                                                          |
| ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 이번 수업의 목표(h2·p)와 동반 캐릭터                                            | 강의 시작 표지에 이미 목표가 있으므로 표지로 일원화한다. 본문 첫 화면에는 넣지 않는다. 캐릭터 아이콘은 폐기한다. |
| 환경 메모(small). Conversation·FirstFile은 실습/복습 모드에 따라 문구가 바뀐다  | 본문 상단 제목 아래 한 줄. 모드 문구도 그대로 유지한다.                                                          |
| 이전 설명 / 첫 화면의 "N-M …으로"(이전 수업) / 표지 복귀                        | 하단 ← 버튼. 첫 화면에서는 이전 수업 또는 표지로 가며, 라벨에 목적지를 쓴다.                                     |
| 다음으로 / 학습 정리 보기 / 마지막 "…로 →"와 부수효과(기록·dispatch·onComplete) | 하단 → 버튼. 동작과 비활성 조건은 그대로 유지한다.                                                               |
| 단계 수                                                                         | 하단 점으로 표시한다. 이미 지난 화면만 누를 수 있다. 헤더의 "화면 n / N"과 겹치면 헤더 쪽은 뺀다.                |
| 현재 안내로 돌아가기 ↑                                                          | 하단 바 왼쪽 위의 작은 버튼으로 유지한다. 필요한 경우에만 나타난다.                                              |
| 입력 마치기(모바일 키보드)와 keyboard-open CSS                                  | 하단 바 안에 둔다. 키보드가 열렸을 때만 보인다.                                                                  |
| Review·Practical(단계 없는 화면)                                                | 같은 하단 바에 점 없이 버튼만 둔다.                                                                              |

- **키보드:** 인트로와 같이 ←/→로 이전·다음 화면으로 간다. 다음이 막혀 있으면 이동하지 않는다. 입력칸에서는 동작하지 않는다.
- **본문 폭:** 패널 열(250px)이 사라진 만큼 본문을 넓힌다. 다만 읽기 폭은 유지한다.
- **스타일 정리:** `.lessonPanel` 규칙은 `WorkbookLesson.module.scss`와 `WorkbookClass.module.scss` 두 곳에 있으므로 함께 정리한다.

## 수업 공통 레이아웃 상세 (2026-10-30 사용자 결정)

인트로의 틀을 그대로 쓴다.

```
┌ 상단 줄 ─────────────────────────────────────────────┐
│ 1단원 · 1-1 AI 이해하기                       3 / 11 │
│ ← 단원 지도 보기                                     │
├ 종이 카드(본문) ─────────────────────────────────────┤
│  화면 제목                                           │
│  본문 · 예시 · 퀴즈 · 입력 (위에서 시작, 읽기 폭 유지) │
├ 하단 바 ─────────────────────────────────────────────┤
│ ← 이전      ● ● ● ○ ○ ○  3 / 11      [퀴즈에 답하면…] 다음 → │
└──────────────────────────────────────────────────────┘
```

- **바탕:** 인트로처럼 바깥은 검정, 본문은 따뜻한 흰 종이 카드다('읽기 표면은 종이' 규칙). 예시 카드·입력칸·퀴즈의 색도 종이 위 색으로 바꾼다.
- **진행 표시:** 화면마다 점을 두고 옆에 "3 / 11"을 작게 붙인다. 지나온 화면의 점만 눌러 돌아갈 수 있다. 아직 보지 않은 화면은 막는다(퀴즈·필수 입력 우회 방지). 모바일은 번호만 보인다.
- **다음이 막혔을 때:** 하단 바의 "다음" 옆에 이유를 한 줄로 보여준다(예: "퀴즈에 답하면 넘어갈 수 있어요"). 누르면 해당 문제나 입력으로 스크롤한다.
- **카피바라:** 수업 본문에서는 뺀다. 카피바라는 인트로·표지·지도에서 만난다('학습과 성취가 먼저').
- **이전/다음 문구:** 첫 화면의 ←는 "표지" 또는 "이전 수업(N-M)"으로 목적지를 쓴다. 마지막 화면의 →는 기존 마무리 문구("학습 마치고 단원 지도로" 등)와 동작(기록·완료 처리)을 그대로 쓴다.
- **키보드:** 인트로와 같이 ←/→로 이전·다음 화면. 다음이 막혀 있으면 넘어가지 않는다. 입력칸에서는 동작하지 않는다.
- **이번 수업의 목표:** 표지에 있으므로 본문에는 두지 않는다. 실습/복습 환경 문구는 본문 제목 아래 한 줄로 둔다.

## 작업 순서

1. 인트로를 강의 시작 직후로 옮긴다. 1-1에 표지를 붙이고, 예시 화면을 빼고, 지도에 "인트로 다시 보기"를 둔다.
2. 공통 하단 바 컴포넌트를 만든다. 1단원 5개 수업(1-1 ~ 1-5)을 옮긴다. PC·모바일 디자인 체크 후 사용자 확인을 받는다.
3. 나머지 2~5단원 수업 11개와 Review·Practical을 옮긴다. 패널 스타일을 지운다. e2e를 갱신한다.

## 진행 기록

- **1단계 완료 (2026-10-30):** 처음 "강의 시작하기"를 누르면 `?view=intro`로 클래스 인트로가 열린다. 예전 링크 `view=examples`도 인트로로 연다. "첫 수업 시작"은 1-1 표지로 간다. 1-1은 다른 수업과 같은 강의 시작 표지를 쓰고, 표지와 인트로 사이의 왕복 상태(`class-intro-return`)는 없앴다. 지도 상단 "클래스 소개 보기" 옆에 "인트로 다시 보기"를 두었다. 다시 볼 때는 인트로의 나가기가 "← 단원 지도 보기"로 지도로 돌아간다. 처음 시작이면 "← 클래스 소개로"다. 인트로 상단 표기는 "WEB CLASS · 클래스 인트로"로 바꿨다. 모바일에서 인트로를 주소로 바로 열어도 워크북 메뉴 띠를 접는다.
- **남은 정리:** 예시 화면 컴포넌트 `WorkbookExampleBrowser.tsx`는 시작 흐름에서 빠져 쓰이지 않는다. 파일 삭제는 권한 확인에서 막혀 아직 남아 있다. 관련 스타일도 함께 남아 있다. e2e 7개 파일(`workbook-first-visit`, `workbook-map-panel`, `workbook-purpose-preview`, `workbook-keyboard`, `workbook-lesson-routing`, `workbook-release-basics`, `workbook-full-preview`)이 예전 시작 흐름(예시 화면·1-1 인트로)을 전제하므로 3단계에서 갱신한다.
- **1-0 지점으로 변경 (2026-10-30 사용자 결정):** 인트로의 시작 위치를 첫 지도로 옮겼다. "강의 시작하기"(처음) → 첫 지도 → 출발 선착장의 1-0 "클래스 인트로"(시작점 표시, 오른쪽 패널 "여기서 시작해요") → 인트로 → "첫 수업 시작" → 1-1. 1-0은 다른 지점처럼 카피바라가 걸어가고 패널 카드의 "인트로 보기"로 연다. 진행도·해금에는 넣지 않는다(이번 방문의 열람 여부 `class-intro-seen`은 시작점 표시에만 쓴다). 인트로를 본 뒤에는 1-1이 다음 목표가 된다. 지도 상단 "인트로 다시 보기"는 다른 단원 지도에서도 쓰도록 유지했다.
- **지도 우측 패널 정리 (2026-10-30):** 위 AGENTS.md 기준으로 바꿨다. 지도 위의 "n / N 학습 확인"은 패널 머리로 옮기고, 지도 상단의 "인트로 다시 보기"는 패널 아래로 옮겼다. 수업 카드 메타는 "1-1 · 다음 수업/선택한 수업/학습 확인"으로 줄였다. e2e에서 "이어서 배울 수업"·"수업에서 배울 내용" 접기·지도 위 학습 수를 찾는 검사는 3단계에서 갱신한다.
- **공통 틀 1차 적용 (2026-10-30):** 수업마다 코드를 고치지 않고 공통 스타일(`WorkbookLesson.module.scss`, `WorkbookClass.module.scss`)에서 전 수업에 적용했다. 오른쪽 패널 열을 없애고 패널을 본문 아래 하단 바로 바꿨다(이전은 왼쪽 글자 버튼, 다음은 오른쪽 채운 버튼). 패널의 목표·카피바라 메모는 숨겼다. 본문은 가운데 약 960px 읽기 폭으로 모았고, 수업 화면은 `.paper`로 종이 바탕이다. 1-1(이 모듈 패널)과 1-4(수업 모듈 패널)에서 PC·모바일로 확인했다. 아직 하지 않은 것: 하단 점 진행 표시, 다음이 막혔을 때 이유 한 줄, ←/→ 키보드, 첫 화면 ← 문구 정리, 수업 컴포넌트의 패널 마크업 정리.
- **공통 하단 바 기능 (2026-10-30):** `WorkbookLessonSteps.tsx`가 모든 단계형 수업(16개)의 하단 바 가운데에 단계 점과 "n / N"을 둔다. 수업 머리(`WorkbookLessonHeader`)가 현재 화면을 알리고, 표지(`WorkbookLessonCover`)가 상태를 담는다. 수업마다 코드를 고치지 않고, 하단 바가 각 수업의 이전/다음 버튼을 대신 눌러 동작한다(퀴즈·필수 입력 규칙은 수업의 것을 그대로 따름).
  - 점: 지나온 화면만 눌러 돌아간다(이전 버튼을 필요한 만큼 누름). 모바일은 "n / N"만 보인다. 머리의 "화면 n / N"은 뺐다.
  - 다음이 막히면 버튼 옆에 이유 한 줄: 보기를 고르면 / 빈칸을 채우면 / 확인 항목을 체크하면 / 이 화면의 활동을 마치면 넘어갈 수 있어요. 누르면 해당 보기·입력칸으로 스크롤한다. 이유는 화면의 상태로 추정하므로 수업별 정확한 문구는 후속으로 다듬을 수 있다.
  - ←/→: 이전·다음 버튼과 같다. 입력칸·열린 대화상자·수정 키 조합에서는 동작하지 않는다.
  - 첫 화면의 ←는 "← 표지로"다.
- **인트로와 하단 바 통일 (2026-10-31):** 사용자 피드백(인트로 쪽 디테일이 더 좋다)으로 인트로 하단 바 값을 기준으로 공통 믹스인 `workbook-step-button`·`workbook-step-next`·`workbook-step-dots`(`src/styles/_mixins.scss`)를 만들어 인트로와 수업 양쪽이 쓴다. 다음 버튼은 짙은 초록(#283d33), 점은 24×32 칸에 6px 점·현재 15px, 이전은 글자 버튼이다. 수업의 "n / N" 숫자는 화면 읽기용으로만 남기고 점만 보인다(모바일도 점). 이전에는 ←, 다음에는 →가 문구에 없으면 붙는다.
