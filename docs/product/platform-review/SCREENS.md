칸 표기(2026-11-10 1차 검수 끝): ` ` 아직 · ✅ 검수 끝(발견은 FINDINGS에) · ➖ 해당 없음(이유를 비고에) · ⏳ 진행 중.
한 화면을 상태별로 여러 번 연다. 같은 행의 PC와 모바일을 둘 다 채워야 끝난다.

## 상태 만드는 법

- **입금 대기:** 처음온사람으로 `prompt-clinic` 신청.
- **확정(유료):** 위 다음 모쏘운영으로 `/demo/platform/ops`에서 입금 확인.
- **환불 요청:** 확정된 유료 주문 → `/me/orders/[no]`에서 요청 → 모쏘운영이 시험장에서 승인.
- **대기(정원 초과):** `tonight-mogakco`(1자리)에 두 사람이 차례로 신청.
- **승인 대기 클럽:** 처음온사람으로 `ai-video-club` 가입 신청.
- **처음으로 되돌리기:** `supabase db reset` 또는 시험장의 초기화. 상태를 만든 순서를 FINDINGS 근거에 적는다.
