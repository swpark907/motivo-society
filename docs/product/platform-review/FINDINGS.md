- 상태: **1차 검수 끝(2026-11-10).** 화면 42행 PC·모바일, 여정 J1~J4와 상태 화면 묶음(S1)을 끝까지 따라갔다. 커밋은 하지 않았다.

## 기록 규칙

- 한 행 = 발견 하나. ID는 `F-` + 세 자리, 지우지 않는다(잘못 본 것은 처리 칸에 `오탐`).
- **근거:** 사람 · 너비 · 주소 · 상태를 만든 방법 · 측정값이나 스크린샷 설명. 다른 세션이 같은 걸 재현할 수 있어야 한다.
- **처리:** `열림` → `고침(확인)` + 바꾼 파일 / `결정 대기: 누가 무엇을` / `오탐: 이유` / `미룸(P2): 이유`.
- 화면 여러 곳에 같은 문제가 있으면 행 하나에 화면을 모두 적는다(공용 컴포넌트에서 한 번에 고친다).

## 오탐 · 환경 메모 (반복해서 걸리는 것)

- **하이드레이션 경고 `data-wxt-integrated`:** 개발 화면 왼쪽 아래 "1 Issue"가 뜨지만 사용자 Chrome의 확장 프로그램이 `<div hidden>`에 속성을 넣어서 생긴다. 앱 문제가 아니다. 내장 브라우저나 Playwright에서는 안 뜨는지로 구분한다.
- **카드 제목 링크(23px):** 카드 전체를 덮는 링크라 실제 누름 영역은 크다(LOG L12 · 호스트 점검에서 같은 판정).
- **로그인 화면 접힌 개발용 버튼:** 이름 없는 버튼으로 잡히지만 개발 환경 전용(L12).
- **Chrome 창 크기로는 375가 안 된다:** 최소 폭에 막힌다. 모바일은 내장 브라우저 `resize_window {preset:"mobile"}` 또는 Playwright 뷰포트로.
- **`workshop-followup`은 시드에 표지가 없다:** 기본 표지(종류 색 + 제목)가 맞게 나오는지 보는 용도. 표지 없음 자체는 발견이 아니다.
- **로그인 화면 접힌 개발용 영역의 요약 줄(309×32):** 개발 환경 전용이라 누름 영역 기준에서 뺀다.
- **완주 링(`conic-gradient`):** 진행을 보여 주는 데이터 표시라 D3의 장식 그라디언트가 아니다.
- **파일 입력(14.4px):** 글자를 치는 칸이 아니라 아이폰 확대가 일어나지 않는다(M5 제외).
- **문장 안 링크(예: "AI 도구 실습 워크숍" 121×19):** 문장 속 링크는 누름 영역 기준의 예외(WCAG 2.5.8 inline).
- **체크박스 · 라디오(13~20px):** 감싼 라벨이 누름 영역이다. 호스트 관리 · 만들기 화면에서 재 보니 라벨이 모두 44px 이상(공지 대상 88×44, 단계 카드 311×94 등).
- **회원 홈 "내 사람들"의 활동 이름 링크(115×15):** 기록 한 줄 안의 문장 속 링크라 예외로 둔다.
- **GNB의 숨은 "진행 중" 제목:** 개발용 테스트 메뉴(운영 빌드에는 없음).
- **모션 줄이기:** 플랫폼 화면에는 키프레임 애니메이션이 없고 전환은 모두 120ms 색·불투명도라, 모션 줄이기에서 끌 움직임이 없다(C5 충족).
- **이미 결정 대기인 것은 발견으로 다시 올리지 않는다:** `--white` 직접 사용 · 참가자 얼굴 공개 · 메일·푸시 발송 · 환불 계좌 등(BACKLOG "결정 대기"·"후속").
