## 5. 후속 전문가 사용성 점검 — 첫 수강생 흐름 · 2026-10-21

### 조사 범위와 증거의 한계

**실제 초보자를 모집한 사용자 테스트가 아닌 전문가 휴리스틱 점검이다.** 아래 혼란은 관찰한 화면 구조에서 예상하는 위험이며 실제 이탈·오류율을 측정한 결과가 아니다. 기존 홈·소개·첫 수업 CUA 조사와 1·2단원 검수, 롤백 후 3·4단원 PC·모바일 검수를 재사용했다. 이번 후속에서는 기존 로컬 서버의 클래스 소개부터 목적 미정 선택→지도 이동→첫 수업 진입을 다시 직접 조작하고, PC 1440×900·모바일 390×844의 첫 설명을 새로 저장했다. 모바일 다음/이전 설명 이동도 확인했다.

1·2단원의 후반부는 롤백 마감 전체 E2E에서 저장한 실제 렌더링 화면과 현재 원고·완료 조건을 대조했다. 이번에 외부 AI를 실행해 자기 파일을 새로 제작하거나 1~4단원을 처음부터 끝까지 수동 재수강한 것은 아니다. 기존 E2E의 ‘실제 적용’ 화면은 테스트용 본인 확인 데이터이며 실제 외부 파일 제작 증명이 아니다. 3·4단원 독립 미리보기에는 실제 클래스의 좌측 메뉴 띠가 없으므로 모바일 여백 판단은 실제 클래스에서 확인한 증거를 사용했다.

### 첫 수강생이 만나는 순서

홈에서 따뜻한 작업실과 클래스를 발견하고, 소개에서 ‘내 콘텐츠를 담은 작은 웹페이지 하나’라는 결과를 이해한다. 강의 시작→목적 선택→지도 이동→수업 시작 뒤 AI 설명을 읽는다. 도구 준비 후에는 요청 예시를 복사해 외부 AI 앱으로 옮기고, 만들어진 파일을 브라우저에서 확인한 뒤 워크북에 돌아온다. 2단원에서는 같은 파일에 자신의 제목·대상·목적·소개·내용을 담는다. 3·4단원 기본 과정은 화면 비교와 메모 시뮬레이션이며 자기 파일 적용은 접힌 선택 영역이다.

처음 배울 가치와 결과물은 이미 설명돼 있다. 개선의 중심은 그 가치에 도달하기 전의 진입 절차, 실제 제작과 직접 관련 없는 상태 조작, 작은 화면의 반복 안내다. **요청 예시→복사→외부 AI 실습→결과 확인은 유지한다.**

## 6. 승인된 UX 개선 구현 — 2026-10-21

분석 뒤 사용자가 개선 실행을 승인했고 이 대화에서도 ‘승인한 범위로 계속 진행’을 확인했다. 기존 백업은 유지하고 이번 직전 파일은 `/private/tmp/workbook-ux-implementation-20261021/before`와 `before-manifest.json`에 별도 보존했다. 무관한 작업을 되돌리지 않고 아래 범위만 수정했다.

### 반영한 범위

- **1·2단원 마지막 행동 통합:** 체크·관찰 뒤의 성공/문제 라디오, 별도 결과 저장, 별도 재확인 대기 버튼을 제거했다. 마지막 ‘기록하고 계속하기’에서 학습 확인과 실제 결과를 함께 저장한다. 실제 모드에서 체크·기획·선행을 충족할 때만 목표 확인으로 남고, 미확인 항목은 관찰을 근거로 대기한다. 예시 모드는 기존 실제 결과를 덮어쓰지 않는다. 새 필수 입력이나 상태 스키마를 만들지 않았다.
- **기획→요청 연결:** 별도 ‘기획을 작업 기준으로 적용’을 제거했다. 요청 생성/갱신에 현재 기획 기준 적용을 결합하고, 기존에 편집한 요청으로 다음 단계에 갈 때도 기준을 반영한다. 편집 요청을 자동으로 덮어쓰지 않으며 실제 파일 변경으로 간주하지 않는다. 과거 확인 뒤 파일을 바꾼 경우의 재확인은 접힌 추가 안내에서 유지한다.
- **외부 실습 왕복:** 질문/수정 예시와 복사 버튼을 유지하고 복사 옆에 AI 앱 전송→같은 파일 확인→워크북 복귀를 붙였다. 붙여넣기·파일 열기·복사 실패 안내도 보존했다.
- **진입 단축:** 처음 강의 시작→목적 선택 두 행동으로 첫 수업이 열린다. 목적 미정도 가능하며 지도는 수업에서 돌아가 탐색한다. 이어하기도 남은 학습으로 직접 연결하고 목적 변경은 기존 지도로 돌아간다. 작은 캐릭터와 짧은 실험은 보존했다.
- **모바일 읽기:** 접힌 메뉴 버튼을 수업 헤더 첫 행으로 옮겨 빈 띠를 제거하고 본문 앞 반복 목적 안내를 접었다. 하단의 반복 단계 표시는 모바일에서 숨기고 기존 다음/이전·지금 할 일은 유지했다. 결과 모아보기와 행동 복귀는 같은 행을 사용한다. PC 학습 안내와 작은 캐릭터는 유지했다.
- **조작 근접 배치:** 4단원 기본 입력 실습 앞의 목적별 기능 설명은 접고 선택 상세 보기 실험은 기본 조작 뒤로 옮겼다. 표시/저장 시뮬레이션의 범위와 학습에 쓰이는 관찰·기획은 유지했다. 기본 과정에 적용/생략 이유를 다시 요구하지 않는다.
- **기록 보존:** 2단원 기록 편집이 3~5단원 기록·적용·완료를 초기화하던 부모 연결을 제거했다. 1단원 실습 기록 편집도 기존 학습 이력을 삭제하지 않는다. 현재 체크 철회와 공통 기준 변경의 실제 재확인은 유지하며 과거 기록을 새 외부 파일 성공으로 승격하지 않는다.

### 5단원에 대한 공통 영향

5단원 개별 원고·예시·배포 안내·판정 파일은 수정하지 않았다. 공통 모바일 헤더/메뉴/하단 행과 클래스 이어하기는 5단원에도 적용된다. 또한 앞 단원 기록 편집으로 기존 5단원 기록을 지우던 연동이 제거됐다. 실제 배포·공유·커밋은 하지 않는다. 이 공통 영향은 전체 여정 회귀검사에 포함한다.

### 검수 증빙과 마감

이 절의 검수는 실제 초보자 사용성 실험이 아니다. 새 UI의 PC·모바일 실제 화면과 키보드 조작, 회귀 검사로 확인한다. 외부 AI에서 학습자 파일을 실제 제작하지 않는다. 전후 증빙은 앞 절의 `/private/tmp/workbook-ux-followup-20261021`과 이번 `/private/tmp/workbook-ux-implementation-20261021`에 구분한다. 후속 검사 결과를 아래에 추가한다.

#### 실패를 보완한 과정과 최종 확인 범위

- 초기 집중검사: 32경로 중 26통과·1제외·5실패였다. 지도 패널 PC/모바일 2실패는 ‘학습 이어가기’가 지도에 머물고 첫 장소를 가리킨다는 예전 기대였다. 이제 다음 미완료 수업으로 바로 열리므로, 지도로 명시적으로 돌아가 다음 장소가 현재 위치인지 검사한다. 모바일 전체 여정 3실패는 기획 편집 뒤 후속 수업이 잠기고 기록이 사라져야 한다는 예전 기대였다. 기존 후속 복습과 적용 기록이 그대로 남는지 비교하도록 교체했다.
- 전체 회귀 실행: 200경로 중 193통과·모바일 노트북 전용 1제외·6실패였다. PC 서비스 경로는 새 대기 저장 검사의 상태 선택자가 요약/수업 두 영역을 동시에 찾았으므로 현재 영역으로 한정했다. PC 나머지 2경로는 예시 전환 뒤에도 학습이 보존돼 ‘시작’ 대신 ‘다시보기’가 나타나는 변화에 맞춰 검사했다. 모바일 3경로는 펼친 영역의 innerText를 전체 textContent와 비교하던 검사 자체를 같은 textContent 기준으로 고쳤다.
- 보완 중 PC 3경로에서 기존 실제 적용 기록까지 보존돼 적용 개수가 2/4가 아닌 3/4이고 남은 작업이 기획이 아닌 데이터인 점도 확인했다. 예시로 전환해도 앞선 실제 확인이 유지된다는 기준에 맞춰 개수·남은 작업·추가 적용 수를 조정했다. 테스트 입력으로 상태를 주입하거나 성공 판정을 느슨하게 바꾸지 않았다.
- 최종 목적별 전체 여정 재실행: **PC/모바일 6경로 전부 통과(1.7분)**. 초기 전체 회귀의 나머지 193통과와 합쳐 모든 실행 대상 199경로가 보완 후 확인됐다. 전체 200경로를 다시 한 번 모두 돌렸다는 뜻은 아니다.
- 대표 PC 경로는 체크 하나를 비워 마지막 버튼으로 대기를 저장→다시 열어 관찰/대기 보존 확인→체크를 마친 뒤 같은 버튼으로 목표 확인 저장까지 검사한다. 2단원도 별도 라디오/저장 없이 마지막 버튼에서 실제 확인이 남는지 확인한다. 모든 목적에서 기획 초안 편집 후 3~5단원 복습과 기존 적용 기록이 보존되는지 검사했다.
- 최종 `pnpm check`: 타입·린트·포맷·Vitest **29파일100테스트 통과**. 순수 판정 모듈과 공통 상태 스키마는 변경하지 않았다. CUA에서 PC1440×900/모바일390×844 실제 첫 수업을 열고, 두 행동으로 진입·모바일 메뉴 열기/닫기·목적 안내의 Enter 펼치기를 확인했다. 모바일 첫 화면에서 AI 정의까지 읽을 수 있고 별도 메뉴 띠가 사라진 것을 전후 캡처로 비교했다.
- 자체 코드 리뷰에서 부모의 후속 기록 초기화 연결, 과거 미저장 문제 초안의 접근성, 왕복 안내의 순서 불일치를 확인하고 보완했다. 과거 문제 초안은 같은 기존 키의 접힌 읽기 영역에서 보존한다. 현재 체크 철회/기준 변경의 재확인은 유지한다. 짧은 PC 화면에서 우측 설명이 이동 버튼을 밀어내는 부분도 설명 영역의 스크롤로 보정하고 마감 검사한다.
