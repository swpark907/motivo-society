# 책상 정리 데모

2026-09-28 사용자 승인으로 제작한 독립 데모. 경로는 `/demo/workbook-desk`이며 기존 워크북 홈은 변경하지 않는다.

## 검증할 경험

방향·간격·정렬을 조작 → 실제 배치 변화 관찰 → 작은 도전 → CSS 원리 확인 → 현재 설정을 AI 요청 문장으로 연결한다. 재미와 이해를 평가하기 위한 프로토타입이며 발행된 커리큘럼이 아니다.

- 승인된 완성 시안에 맞춰 작업실 배경과 투명 PNG 책·찻잔·화분을 분리해 사용한다. 물리 엔진이나 드래그는 사용하지 않는다.
- 배치에는 실제 Flex를 사용한다. 세 칸은 화면 폭과 방향에 맞춰 같은 크기로 조정되며 gap은 그림이 아닌 칸 사이의 거리다.
- 기본 상태는 가로·8px·시작 정렬. 목표 그림처럼 가로·가운데·여유 있는 간격(16~32px)을 만들면 성공이다. 정확한 픽셀 맞히기보다 배치 개념에 집중한다.
- 확인 버튼을 누르면 방향 → 간격 → 정렬 순으로 부족한 조건을 안내한다. 수치 힌트는 별도 버튼으로 펼친다. 실패 횟수 제한은 없다.
- 도전 성공 시 원리가 열리며, 성공 전에도 원리를 직접 열 수 있다.
- 물건의 칸은 점선, gap은 색 띠로 표시하며 표시를 끌 수 있다. 모바일에서는 축소된 미리보기를 조작 패널 위에 고정한다.
- 웹 카드에 적용하면 소개·작업·기록 카드가 같은 방향·간격·정렬로 바뀌며 이후 조작도 함께 반영된다. 초기화하면 연결을 해제한다.
- 배치를 바꾸면 CSS와 요청 문장도 현재 값으로 갱신한다. 웹 카드 연결 후에는 요청 대상도 웹 카드로 전환된다. 성공 상태는 현재 배치 기준이며 완료 기록은 저장하지 않는다.
- AI 호출은 없다. 생성된 요청 문장을 외부 AI 도구에 직접 사용하도록 안내한다. 클립보드 접근 실패 시 직접 선택해 복사할 수 있다.
- 키보드로 선택 버튼과 range를 조작할 수 있다. 자동재생·소리·움직이는 장식은 없다.

## 이번에 다루지 않는 것

계정·진도 저장·추천·실제 AI 실행·결과물 제출·배포·캐릭터 애니메이션. 장면의 재미와 조작-개념 연결을 먼저 확인한다.

## 사용자 피드백에서 확인할 것

- 설명 전에 조작할 마음이 드는가?
- 간격과 정렬의 차이를 화면에서 알아볼 수 있는가?
- 도전이 너무 뻔하거나 설명이 길지는 않은가?
- AI 요청으로 연결하는 마지막 단계가 자연스러운가?

## 배치 영역 조정

가로 물건은 전경 지도와 겹치지 않도록 위로 올렸다. 배치 영역의 외곽 점선은 항상 표시한다. 세로는 소품 칸을 데스크톱 120px, 모바일 64px로 유지하고 영역 내부를 스크롤한다. 세로 Flex 내용에는 정렬 차이를 관찰할 여유 공간 64px를 추가한다. 외곽 점선은 스크롤 뷰포트이며 세로 컨테이너의 전체 높이는 그보다 길다.
