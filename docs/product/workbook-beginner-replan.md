# 완전 입문 기준의 재계획 초안

2026-10-06. 첫 수업 원고 `workbook-lesson-01-ai.md`를 기준으로 논의할 순서다. 기존 4+1 전체 구조를 변경한 확정안은 아니다. 지금은 첫 수업의 설명 깊이와 학습 경험을 먼저 검토한다.

## 합의한 입문 학습 순서

사용자 승인(2026-10-06): 개념과 도구를 알기 전에 수정 요청부터 체험하는 이전 순서를 변경한다. 아래 1~5의 학습 순서를 기준으로 진행하며, 실제 차시 수와 지도 배치는 아직 정하지 않는다.

| 순서 | 수업                           | 도달할 판단·행동                                                                                                     |
| ---- | ------------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| 1    | AI 이해하기                    | 무엇을 도와줄 수 있는지와 결과를 확인해야 하는 이유를 안다. 짧은 예시 결과를 살펴보며, 요청·수정 실습은 하지 않는다. |
| 2    | AI 종류와 도구 알아보기        | 대화·이미지·코딩 등 용도와 모델·도구의 차이를 가볍게 이해한다. 브랜드 이름 암기를 목표로 하지 않는다.                |
| 3    | 사용할 도구 준비하기           | 선택한 도구에 웹으로 접속하거나 필요한 프로그램을 설치하고 첫 사용을 준비한다. 이미 준비한 사람은 확인 후 넘어간다.  |
| 4    | AI와 첫 대화하기               | 간단히 요청하고 답변을 확인한 뒤 구체적인 수정 요청까지 직접 해본다.                                                 |
| 5    | 에이전트와 바이브코딩 이해하기 | 대화에서 파일 제작·수정으로 이어지는 방식과 사람이 작업 범위·결과를 확인하는 역할을 이해한다.                        |

이후 연결 제안은 ‘AI와 첫 화면 만들어보기 → 홈페이지 기획하기’다. 제작 도구가 대화 도구와 다르면 실제 제작 전에 추가 준비를 안내한다. 도구 선정과 구체적인 설치 절차는 미확정이다.

첫 수업의 소개문 사례에서 수정 요청을 비교하던 활동은 4번 수업의 소재로 옮긴다. 그때는 준비된 실제 도구로 요청하고 확인하며, 사전 제작 예시는 보조 자료임을 명시한다. 카피바라는 사용자와 함께 처음 배우는 동료로 등장한다.

각 수업이 별도의 지도 건물을 요구하는 것은 아니다. 하나의 학습 지점 안에서 여러 짧은 수업을 제공할 수도 있다.

## 수강 환경과 도구 준비 기준

사용자 확정(2026-10-06): 개인 컴퓨터에서 실습하고 모바일은 복습에 활용한다. 두 번째 수업의 구성과 기본 도구 하나로 시작하는 방향도 승인했다. 특정 제품은 아직 선정하지 않았다.

- 컴퓨터: 수업 설명을 보면서 외부 AI 도구를 준비하고, 직접 요청·결과 확인·수정과 이후 웹 제작을 진행한다.
- 모바일: 설명·예시·핵심 정리를 다시 읽고 확인 문제로 복습한다. 모바일에서 실습 안내를 읽었다는 이유로 실제 컴퓨터 실습을 완료 처리하지 않는다.
- 세 번째 수업 제작안: 준비할 것 확인 → 사용할 기본 도구 소개 → 웹 접속 또는 필요한 설치 → 계정 접속 및 입력창 확인 → 다음 첫 대화 수업으로 연결. 웹 도구라면 불필요한 설치를 요구하지 않는다.
- 설치 여부 체크 하나로 수업을 대체하지 않는다. 실제 도구 선정 후 초보가 접하는 화면과 용어, 준비 완료를 확인하는 방법까지 설명한다.
- 사용자 확정(2026-10-06): Windows와 Mac을 모두 지원한다. 도구 선정 후 필요한 OS별 안내를 준비한다. 구체 도구와 지원 OS 버전은 미결이다. 모바일 복습 방향이 계정·기기 간 진도 동기화 구현 승인을 뜻하지는 않는다.

## 기존 맵과의 관계

AI 입문을 시작 지역으로 둘지 1월드 앞부분으로 넣을지는 미결이다. 먼저 원고 1개를 검토하고 후속 입문 수업의 실제 분량을 확인한 뒤 결정한다. 기존 맵의 8개 건물에 맞추려고 개념을 생략하거나 단원을 억지로 합치지 않는다. 지도·캐릭터는 학습 목차와 사례를 돕는다.

6. 실제 분량을 보고 월드·학습 지점 배치와 진도 구조를 다시 확정한다.
