현재 사용자 결정 대기는 계정 보상/저장 정책과 별도 홍보 포스터 선택이다. 기존 클래스의 쉬운 문구·내용·상호작용 개선은 사용자 결정 대기가 아니다. 현재 실행 담당의 시각검수만 CUA `Browser is not available: iab` 결과로 막혀 있으며 읽기/문서 감사는 이어갔다.

시점 주의: 위 active는 조회 순간이다. 현재 보고 턴 종료 이후에는 이 세션도 idle로 바뀔 수 있다. 새 작업 실행 여부는 큐 기록과 최근 결과를 함께 확인하고, 표만 보고 실행 중이라고 약속하지 않는다.
