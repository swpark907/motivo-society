# 커리큘럼과 지도 지점 정렬 · 2026-10-16

사용자 요청으로 세부 주제가 늘어난 뒤 지도 지점도 함께 검토했다. 이전에는 소개와 본문에 추가한 다섯 ‘실전 심화’가 지도에서 독립적으로 열리지 않았고, 기본 목차 주제도 어느 지점에서 다루는지 대응이 드러나지 않았다.

## 실제 변경

| 지도             | 이전 지점 | 현재 지점         | 추가한 선택 곁길                               | 열리는 조건                     |
| ---------------- | --------- | ----------------- | ---------------------------------------------- | ------------------------------- |
| AI 입문          | 기본5     | 기본5 + 심화1 = 6 | AI 작업 이어가기(지도 짧은 표기: AI 작업 복구) | 에이전트와 바이브코딩 수업 완료 |
| 기획과 첫 제작   | 기본3     | 기본3 + 심화1 = 4 | 기능 범위 정하기                               | 기획·실제 자료 작성             |
| 화면과 사용 경험 | 기본3     | 기본3 + 심화1 = 4 | 디자인 요청 구체화(지도: 디자인 요청)          | 두 화면 관찰과 문제 기록        |

전체 지도 지점은 **17→22곳**이다. 맵 자체의 진입 선행 조건도 유지하며 곁길을 통해 잠긴 월드나 기본 학습을 건너뛰지 않는다.

기본31주제는 같은 제작 행동에서 다루는 것끼리 기존17지점에 묶고, 추가5주제는 독립 심화5지점에 연결했다. 따라서 소개의36주제를36개의 별도 수업·장소로 나누지는 않았다. 주제는 `src/lib/workbook-curriculum.ts` 한 곳에서 소개와 지도 패널에 공급한다. 각 기본 지점의 ‘이곳에서 다루는 주제’를 열면 소개와 같은 번호·제목이 보인다. 모든 기본 주제가 빠짐없이 한 지점에 대응하는지 순수 데이터 검사로 확인한다.

- 지도에는 기본 경로와 다른 짧은 점선 곁길과 ‘심화/선택’ 표시를 추가했다. 원화는 유지하고 정자·길·다리 주변의 기존 공간을 활용했다. 새 마을/원화/기본 수업은 만들지 않았다.
- 지점 선택 → 우측 패널(모바일 하단) → 수업 시작 → 같은 지도 복귀를 연결했다. 돌아올 때 선택 지점에 키보드 포커스를 돌려준다.
- 심화는 기존 수업 안에서 열던 것과 **같은 활동·같은 선택 기록**이다. 기존 본문과 지도 두 곳에서 접근해도 진행 기록을 따로 만들지 않는다.
- 선택 상황을 다루면 ‘1/3 상황 살펴봄’처럼 표시한다. 정답 인증·외부 작업 완료·기본 학습 완료 횟수를 뜻하지 않는다. 기본 완료/해금과 별도다.
- 지도·수업·목록·브라우저 뒤로 가기에서 심화 선택과 마지막 상황을 방문 context에 보관한다. 기본 장소·기획 입력·제작 요청·완료 기록을 덮어쓰지 않는다. 새로고침·계정/기기 간 저장은 추가하지 않는다.
- 좁은 지도에서 겹치는 라벨은 짧은 표기와 좌/우 정렬로 보정했다. 전체 이름과 선행 조건은 접근성 이름과 선택 패널에서 유지한다.

## 확인 범위

본편 정상 사용자 흐름으로 포인트 수·선행/완료·심화 진입/왕복·방문 기록·목록 왕복을 자동 검증한다. 모든 세부 주제의 지점 대응과 곁길의 실제 종점 대응도 검사한다.

시각 검수는 CUA IAB로 수행한다. `/demo/workbook-map-points`는 **본편과 같은 컴포넌트**의 배치를 검토하는 검색 제외 화면이다. 기본 학습 기록은 비어 있고 지도는 읽기 전용으로 표시하며, 선택 활동 화면은 격리된 방문 context에서 검토한다. 이 검토 경로를 정상 수강의 선행 조건이나 완료 근거로 사용하지 않는다. 실제 본편의 첫 지도/주제 패널 검수와 정상 전체 여정 E2E를 함께 기록한다.

모바일 심화 화면의 하단 안내가 본문을 가리던 문제를 발견해 설명은 PC 보조 패널에 두고 모바일은 복귀 버튼만 간결하게 표시하도록 고쳤다. 곁길 방문을 추가한 테스트에서는 지도 선택 패널과 목록 왕복 후 접히는 기록을 명시적으로 열어 기존 검사를 이어가도록 준비를 맞췄다.

실제 초보 학습자의 Windows/Mac 설치·외부 제작/수정/공개 파일럿은 이번에 수행하지 않았다. 계정/포인트/결제/배포 정책은 기존 결정 대기이며 이번 지도 수정의 선행으로 두지 않는다. 기존3000서버와 다른 담당 파일을 보존하며 커밋·배포하지 않는다.
