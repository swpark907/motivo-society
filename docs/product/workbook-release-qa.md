## 판단과 범위

최종 판단: 현재 구현은 **무료 공개 체험으로 출시 가능한 수준**이다. 유료 판매·외부 AI 도구의 새 기기 설치·실제 배포 완료에 대한 승인이 아니다. 사용자 추가 결정으로 이번 출시는 **무료 공개 체험**이다. 결제·회원 시스템 완성을 이번 출시의 필수 조건으로 삼지 않는다. 누구나 시작할 수 있고, 체험 범위·저장 한계를 이해하며, 학습과 주변 기능을 안정적으로 이용할 수 있어야 한다. 기능 오류뿐 아니라 학습 흐름, UI, 입문자 가독성, 자연스러운 표현, 실제 제공 범위와 소개의 일치, 주변 기능의 연결을 검수한다. 수정 완료 보고만으로 닫지 않고 현재 화면과 관련 회귀 결과로 재확인한다. 가격·환불·결제·회원 정책·배포 서비스는 기존 미결 결정을 임의 확정하지 않는다.

기준 환경: 실행 중인 `http://localhost:3000`, 데스크톱 1280×720 및 모바일 390×844. 기존 작업이 많은 공유 작업 폴더이며 QA는 제품 파일을 직접 수정하지 않고 구현 세션에 요청한다. 테스트는 컴퓨터 부하를 고려해 단일 worker를 기본으로 한다.

- QA-007: 공개 모달에서 과거 시안 탭과 레이어 제작 용어 제거를 실제 확인했다. 수집 완료 설명의 ‘이전 시안에서 기본 제공받은 물건’ 문구는 아직 남아 구현 담당에게 제거 요청했다.
- 학습 완료→홈 받을 수집품→포스터 바로가기→받기→미리 놓기→닫기 시 홈에는 기존 액자 유지→재열기 초안 유지→취소 시 액자 복원→포스터 저장을 확인했다.
- 도시 테마는 기본 액자, 나무 복귀 시 저장한 포스터가 유지되어 테마별 배치 독립을 확인했다. 이 단계에서는 실제 새로고침 뒤 복원·저장 실패·다른 수집품 수령은 확인 전이었다. 이후 새로고침 복원은 실제 확인했고 나머지 수령 경계는 room-storage/received/shortcut 회귀로 확인했다. 저장 불가 전체 환경을 실제로 검증한 것으로 주장하지 않는다.

## 최종 승인 근거
