## 2026-11-06 · L05 활동 상세

- `/activities/[slug]`를 기준 시안 수준으로: 큰 표지(없으면 종류 색 + 제목) → 종류·상태 → 제목·요약 → 핵심 사실(언제 · 어디 · 자리와 확정 방식) → 참가 정보(확정자만: 상세 주소, 온라인은 화상 링크 또는 열리는 시각) → 소개 → 시즌 회차 목록(끝남·오늘) / 챌린지 인증 방법 → 여는 클럽·사람과 진행자 → 신청 전에 알아 두세요(대상 · 비용 · 환불 규정 · 중간 합류) → 이런 활동도 있어요.
- 신청 영역: 넓은 화면은 오른쪽 고정 카드(가격 · 정원 막대 · 안내 · 버튼 · 공유), 좁은 화면은 하단 탭 바 위 고정 바. 버튼 문구는 `apply-state.ts`(순수 함수)가 정한다: 로그인하고 신청 / 신청하기 / 대기 신청 / 중간 합류 신청 / 참가 확정 / 입금·승인 기다리는 중 / 대기 신청됨 / 멤버 전용 / 앞선 활동 참가자 전용 / 모집 마감 / 끝남·취소 / 내가 여는 활동. 실제 신청은 L06이라 신청 버튼은 "준비 중"으로 눌리지 않게 했다.
- OG: 제목·설명 메타 + `opengraph-image`(Pretendard로 표지 위 제목, 표지가 없으면 종류 색 면). 비로그인으로 읽으므로 멤버 공개·작성 중 활동은 새지 않는다. 회차 주소는 시즌 회차 목록으로, 없는·볼 수 없는 주소는 친절한 404(발견·클럽으로).
- 발견 카드가 상세로 연결된다. 공유 버튼은 휴대폰 공유 시트, 없으면 링크 복사.
- 확인: `pnpm check` 통과, `pnpm test:db` 12개 통과, e2e 상세 7개(비로그인 직진입 · OG 이미지 응답 · 회차 이동과 404 · 작성 중 숨김 · 확정자 참가 정보 · 멤버 전용 안내 · 카드에서 상세) 포함 플랫폼 e2e 45개 통과. PC 1024 · 모바일 375에서 시즌 · 확정자 · 멤버 전용 · 챌린지 확인, 가로 스크롤 0. 고친 것: 확정자에게 "확정되면 주소가 보여요"가 남던 것, 오프라인 모임에 화상 링크 안내가 뜨던 것, 챌린지의 빈 참가 정보 칸, 회차 제목의 중복 번호.
- 남은 것: 다음은 L06 신청 흐름. `metadataBase`는 배포 때(후속).

## 2026-11-06 · L06 신청 흐름

- `/activities/[slug]/apply` 한 주소가 신청 전에는 **신청 확인**(비용 · 진행 방식 · 취소/환불 규정, 유료면 입금자명과 규정 확인 체크), 신청 뒤에는 **내 신청 내역**(확정 · 대기와 대기 인원 · 승인 대기 · 입금 안내)을 보여 준다. 실제 판정은 기존 DB 함수 `participation_apply`·`participation_cancel`이 하고 화면은 결과만 그린다.
- 입금 안내: 금액 · 계좌(계좌번호 복사) · 입금자명(복사) · 남은 시간(30초마다 갱신, 첫 화면은 서버 시각으로 그려 하이드레이션 불일치 방지) · 주문 번호. 개발 환경에서만 "시험 계좌, 입금 확인은 시험장 운영 화면에서" 안내.
