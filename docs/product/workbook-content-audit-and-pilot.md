# 기존 클래스 내용 감사와 실제 실습 준비 — 2026-10-13

이번 범위는 이미 승인된 AI 입문과 기본 네 제작 단원의 설명·쉬운 문구·기존 상호작용 개선이다. 이를 새 강의로 취급해 별도 승인을 기다리지 않는다. 새 독립 클래스·필수 기능 확대·회원/보상/비용/계정·배포는 별도 경계다. 코드와 기존 문서를 읽은 감사이며 이번에는 실행 검사나 브라우저 조작을 반복하지 않았다.

## 사용자 결정은 보상·계정 연결 전의 세 가지

근거는 `workbook-direction.md`의 ‘후속 사용자 결정 반영’이다. **필수 학습 최초 완료 1회 포인트**, **큰 단원 추가 보상**, **실제 자기 파일 적용은 별도 상태**는 이미 승인됐으므로 다시 선택하지 않는다. 아래 추천은 아직 결정이 아니다.

| 결정 질문                                                       | 선택지와 추천                                                                                                                                                              | 승인 없이 실제 기능을 연결하지 않는 이유                                                                                                                                 |
| --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 무엇을 소단원/큰 단원으로 묶어 보상할까요?                      | **추천:** 현재 학습 장소의 기존 필수 활동 묶음을 소단원, 해당 마을의 필수 활동 전체를 큰 단원으로 대응. 대안: 각각의 설명 화면/확인 문제를 더 작은 소단원으로 분리.        | 완료/지급의 동일 항목과 큰 단원 추가 보상 조건을 정해야 중복 지급·개정 재지급을 일관되게 처리할 수 있다. 현재 지점 완료를 계정 지급 이력으로 임의 승격하지 않는다.       |

이 세 결정은 **보상·회원 저장 구현의 선행**이고 기존 수업 개선의 선행이 아니다. 지금 외부 배포를 자동 시작하지 않는 경계 역시 별도로 유지한다.

준비표 작성은 계정 생성·설치·유료 이용·파일 업로드·외부 공개의 실행 승인이나 실행 결과가 아니다. 검증 대상은 기존 학습 흐름이며 신규 기능을 추가할 필요가 있는지는 실제 막힌 지점을 확인한 뒤 판단한다.
