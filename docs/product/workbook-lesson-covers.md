# 강의 시작 표지 구현과 검수

2026-10-27. 새 강의가 시작됨을 느끼는 독립된 표지를 기본 17수업 앞에 추가했다. 기존 도입 설명과 합치거나 원고를 줄이지 않는다. 선택 심화는 기존 구성을 유지한다.

## 구성과 색

작은 단원명과 LESSON 번호 → 큰 강의 제목 → 강의 내용의 한두 줄 요약 → 목표 세 가지 → ‘그럼, 한번 시작해볼까요?’와 시작하기 버튼으로 구성한다. PC는 제목과 목표를 두 열로, 모바일은 한 열로 읽는다. 따뜻한 밝은 바탕, 민트 번호·시작 버튼, 연보라 목표 카드를 표지 안에서만 사용한다. 기존 본문과 전역 색은 변경하지 않았다.

PC 제목은 최대 72px, 모바일은 최소 40px로 두고 긴 제목은 자연스럽게 줄바꿈한다. 좁고 낮은 화면은 글자를 축소해 억지로 맞추지 않고 표지 전체를 스크롤한다. 목표 카드는 안쪽 16px, 항목 사이 8px로 좁혔다. 버튼의 최소 터치 높이는 44px다. 자동 넘김·모션·새 이미지 자산은 추가하지 않았다.

## 기존 진도와의 관계

- 시작 전에는 기존 본문을 마운트하지 않는다. 시작 버튼은 `lessonUi[lesson-cover-수업slug]`만 변경하며 학습 완료·실제 파일 성공·해금·입력 내용을 변경하지 않는다.
- 첫 설명 화면 우측 학습 패널의 ‘이전 설명’으로 표지에 돌아간다. 모바일에서는 같은 버튼이 하단에 표시된다. 상단에 별도 제목 복귀 버튼은 두지 않는다. 다시 시작해도 기획 입력과 기존 상태를 유지한다. 표지에는 우측 학습 패널이 없으며 본문 전체 폭을 사용한다. 기존에 첫 설명에서 제공하던 이전 강의 이동은 제목 표지의 ‘이전 강의로’로 옮겨 유지한다. 두 번째 설명 이후의 이전 설명 동작은 그대로다.
- 시작하면 원래 화면 1부터 기존 설명이 나온다. 기존 화면 수에 표지를 더해 번호를 바꾸지 않는다.
- 제목 표지를 다시 여는 동작을 선택하지 않았다면, 시작한 수업은 이번 방문의 지도·소개 왕복에서 기존 설명 위치로 이어진다. 입력과 선택은 기존 Provider가 보관한다.
- 시작 전에 지도로 나가면 학습 완료가 되지 않고, 다시 들어왔을 때 표지가 나온다.
- 새로고침·새 방문은 기존 방문 메모리 정책에 따라 초기화된다. 서버 저장·계정 동기화는 추가하지 않는다.
- 기존 퀴즈·준비·관찰·저장·확인 조건과 URL 직접 진입 정책은 바꾸지 않는다.

## 변경 범위

- `WorkbookLessonCover.tsx`와 전용 SCSS: 표지, 키보드 포커스, 표지 안의 색·반응형 배치.
- `src/lib/workbook-lesson-covers.ts`: 기본 17수업의 목표와 한두 줄 요약. 기존 제목·단원·번호는 `workbook-course.ts`를 재사용한다.
- `WorkbookClass.tsx`: 현재 기본 수업을 공통 표지로 감싼다. 기존 수업 컴포넌트의 본문·콜백·완료 조건은 그대로 둔다.
- `WorkbookLessonHeader.tsx`와 공통 SCSS: 잘못 추가했던 상단 제목 버튼과 전용 간격을 제거했다.
- `WorkbookLessonPrevious.tsx`와 기본 수업 16개 컴포넌트(17수업): 기존 이전 버튼 영역을 감싸 첫 설명일 때 표지로 연결한다. 이후 설명의 이전 동작은 기존 버튼 그대로 렌더링한다. 준비가 안 된 2-2 안내 한 문장만 현재 이동에 맞게 보정했다.
- `e2e/workbook-lesson-covers.spec.ts`: 17수업의 표지·시작과 지도 왕복·기존 잠금 조건을 직접 검증한다. 자동 시작 fixture를 사용하지 않는다.
- `e2e/workbook-test.ts` 및 기존 본문 여정 24개 spec의 import: 표지가 나오면 실제 시작 버튼을 클릭한 뒤 기존 본문 여정을 검사한다. 진도나 기록을 주입하지 않으며 기존 기대 조건을 낮추지 않는다.
- AGENTS·디자인 레퍼런스 목록·이 문서와 검수 캡처.

## 실제 화면 검수

PC 1280×720, 모바일 390×844와 320×740에서 확인했다. [캡처 폴더](../design-references/workbook-lesson-covers-20261027/)의 `ai-cover`, `tools-cover`, `planning-cover`, `screen-cover`, `storage-cover`, `publish-cover`는 각 크기의 대표 표지다. `ai-resumed`는 시작 후 퀴즈가 미확인인 화면 4로 지도 왕복해 돌아온 상태다. `screen-cover-start-mobile320.jpg`는 작은 화면에서 마지막 시작 버튼까지 스크롤·Tab으로 접근한 상태다.

제목 아래의 권유형 문장을 강의 요약으로 교체해 하단 시작 권유와 역할을 나눴다. 17수업 모두 같은 기준으로 정리했고 E2E에서도 권유형 ‘볼까요?’가 표지에 한 번만 나오는지 확인한다.

제목·목표·버튼의 줄바꿈과 간격, 모바일 메뉴 아이콘과 표지 상단 문구의 분리, 스크롤 끝까지 접근을 확인했다. Tab으로 표지 제목에서 시작 버튼으로 이동하고 Enter·Space로 시작하면 기존 본문 제목으로 포커스가 이어진다. 1-1에서 표지만 열거나 시작해도 지도는 0/5이며 다음 수업은 잠겨 있다. 기존 화면 4의 다음 버튼도 결과·정답 확인 전까지 비활성이고 지도 왕복 후에도 그대로다.

## 검사 결과

- 최종 `pnpm check`: 타입·린트·포맷과 33개 파일·115개 테스트 통과 (`check-summary-final.log`).
- 최초 표지 구현의 전체 E2E: **350개 통과** (`full.log`). 제목 복귀·목표 세 가지·간격 보정 후 관련 **80경로 통과** (`revised-final.log`). 제목 아래를 설명형 요약으로 바꾼 최종 상태에서 17수업 표지 왕복·세 목표·중복 권유 제거·입력 보존·전체 17수업 예시 여정 **16경로 통과** (`summary-final.log`). 각 단계의 검사 수를 중복 없는 총합으로 표시하지 않는다.
- 작업 전 518개 파일의 SHA-256과 비교해 기존 본문 여정 24개 테스트는 import 연결 외 변경이 없음을 확인했다. 기존 개별 수업 원고와 완료 판정 코드는 유지했다. 새 표지·데이터·검사·문서·캡처는 별도 추가했다. 근거: `/private/tmp/workbook-covers-20261027/preservation.json`.
- 자체 코드 검토: 표지 복귀 Context는 첫 설명의 기존 이전 버튼 영역에만 연결한다. 기존 이전 강의 이동은 표지에 보존하고 설명 화면 두 번째 이후의 이동 콜백은 변경하지 않는다. 시작 상태는 표시 전용이며 완료 reducer·입력·파일 변경 로직에 연결하지 않는다. 수업 slug별 key로 표지를 분리하고 기존 본문 상태는 Provider에서 유지한다. 본문 내용과 조건을 수정하지 않았다.

초기 검수에서 모바일 상단의 메뉴 아이콘과 문구 간격, 좁은 화면에서 시작 버튼의 위치를 보정했다. 첫 신규 테스트가 기존 화면 2를 퀴즈로 잘못 가정한 것은 원래 퀴즈 위치인 화면 4로 바로잡았으며 제품의 판정은 변경하지 않았다. 기존 본문 여정 검사는 새 시작 버튼을 실제로 눌러 진행한다. 커밋·배포는 하지 않는다.

작업 도중 범위 밖의 WorkbookHome 두 파일과 workbook layout 두 파일에서도 변경을 감지했다. 이번 세션은 해당 네 파일을 수정하지 않았으며 동시 변경으로 분리해 보존했다. 해시 비교 결과는 이 변경까지 포함하므로 모두 이번 표지 작업의 변경으로 집계하지 않는다.

## 이전 설명 위치 정정 — 2026-10-27

사용자 의도는 우측 패널의 기존 이전 설명을 통한 제목 복귀였다. 상단 별도 버튼은 제거하고 17수업의 첫 설명에 같은 방식으로 연결했다. 표지에서는 우측 학습 패널을 렌더링하지 않는다. `ai-first-with-panel-back-*`와 `request-first-with-panel-back-*`는 PC·390px·320px의 현재 위치이며 `*-cover-from-panel-back-*`는 그 버튼으로 복귀한 표지다. 이전 `screen-first-with-cover-back-*`는 잘못된 상단 버튼의 과거 검수 기록이며 현재 구현 근거로 사용하지 않는다.

정정 후 `pnpm check`는 33개 파일·115개 테스트 통과, 관련 PC·모바일 E2E는 **94경로 통과**다. 17수업의 첫 설명은 학습 안내 패널 안의 이전 설명으로 복귀하는지 검사하고, 상단에는 지도 버튼만 남는지 확인한다. 표지 왕복의 기획 입력 보존과 이전 강의에서의 재편집·다시 진입, 기존 퀴즈·저장·해금 조건을 포함한다. PC 1280×720·390×844·320×740에서 우측/하단 버튼→표지, 표지의 우측 패널 부재와 이전 강의 이동을 직접 확인했다. 로그 폴더는 `/private/tmp/workbook-cover-back-20261027/`다. 커밋·배포는 하지 않았다.
