‘잘되는 예시만 넣고 있나요?’는 기존 문서 스키마 v1만 사용한 긴 실습 가이드다. 모임 문의 분류의 가상 사례로 평범한 입력·겹치는 입력·정보가 빠진 입력을 구별하고, 기대 처리와 실제 결과를 비교하는 방법을 안내한다. 실험 결과·고객 문의·성능 수치를 꾸미지 않았다. 참고 자료의 입력·성공 기준·재검사 관점을 적용한 작성자 제안이며 정식 발행 검증을 대신하지 않는다.
