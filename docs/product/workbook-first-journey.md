# 워크북 홈과 첫 여정 구현 계획

2026-10-04. 사용자는 아이디어 수집을 계속하면서 홈의 간단한 기획과 카피바라 맵 기반 학습 기능 제작을 요청했다. 인터뷰에서 첫 주제는 ‘모바일에서 깨지는 소개 페이지 고치기’, 이동은 ‘장소를 누르면 경로를 따라 이동’으로 선택했다.

## 홈 구성

따뜻한 작업실 히어로에서 여정 시작 또는 이어가기를 제공한다. 그 아래 첫 여정 소개, 실제 저장한 발견 기록, 짧은 실험 링크를 둔다. 예시 캘린더·체크리스트·가짜 진도를 제거한다. 맵은 별도 `/workbook/journey` 화면으로 둔다.

## 완성할 범위

- 작업실: 짧은 대화형 이야기와 문제 예상. 자막형 장면으로 시작하며 영상으로 오인하게 표시하지 않는다.
- 정류장: 같은 소개 페이지를 넓은 화면·휴대폰 폭에서 비교. 고정 너비와 유연한 너비, 카드의 가로·세로 배치를 바꿔보고 넘침을 해결한다. 휴대폰만 해결하고 데스크톱을 확인하지 않은 상태는 구분한다.
- 광장: 새 상황 퀴즈, 원리 설명, 자기 프로젝트에 쓸 수정 요청, 발견 메모. 예제 완료와 실제 프로젝트 적용 여부를 구분한다.
- 맵: 클릭한 장소까지 카피바라 이동, 현재 위치와 단계 상태, 키보드로 접근 가능한 장소 버튼. 이전 장소 복습 가능.
- 진행·메모는 이 브라우저 localStorage에 보관. 계정 동기화 없음. 저장 실패를 표시하고 체험은 계속 가능. 초기화는 확인 후 수행.
- 모션 줄이기 설정이면 이동을 즉시 처리. 학습 내용은 모션에 의존하지 않는다.

## 이번 범위 밖

실제 AI 호출, 영상 생성, 외부 알림, 회원·결제, 여러 월드, 공유·개인화 보상. 이후 아이디어 목록에서 별도 검토한다. 기존 책상 데모는 보존한다.

## 완료 확인

홈→맵→이야기→실험→퀴즈·메모→맵·홈 이동, 새로고침 복원, 잘못된 저장 데이터 대응, 모바일·키보드 조작을 확인한다. 기본 검사와 E2E, 데스크톱·모바일 디자인 검토 후 보고한다.
