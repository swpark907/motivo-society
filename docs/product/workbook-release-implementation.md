## QA-024: 최종 정리의 빈 상태

- 예시 복습이 남기는 `mode: pending`만으로 이전 실제 기록이 있다고 취급하지 않는다. 실제 적용 모드나 작성한 결과·근거·문제가 있을 때만 이전 기록을 노출하고 제목을 ‘이전에 남긴 내 파일 기록’으로 변경했다. 원문과 판정은 보존한다.
- 실제 checkpoint·선택 판단·적용 기록이 전혀 없으면 ‘이번에는 예시로 학습했어요. 내 컴퓨터에서 만든 결과를 확인하면 여기에 남길 수 있어요.’ 한 문단만 표시한다. 0개/아직 미확인/최종 미완료의 반복 문구를 제거했다. 실제 기록이 있는 이용자의 목표 개수·확인 근거·재확인은 유지한다.
- 기본 배운 핵심과 남은 일, 학습/프로젝트 완료 판정은 변경하지 않았다.
- QA-024는 위 전체 250개·Vitest·빌드 이후의 UI 수정이다. 수정 뒤 타입·범위 ESLint를 다시 통과했으며 class-summary와 17수업 연속 회귀를 PC·모바일에서 재검증해 **12개 모두 통과**했다(실패/건너뜀/flaky 0, 약 42초). 로그 `/tmp/workbook-summary-final.log`, JSON `/tmp/workbook-summary-final-results.json`.
