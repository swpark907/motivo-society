# 기획과 첫 제작 독립 지도 — 2026-10-08

최신 마을 지도 구별 적용과 실제 두 폭 검수는 [자산 매핑 문서](workbook-village-map-assets.md)를 따른다. 기존 준비 자산 map.png의 호수·절벽 지형과 서로 다른 좌표·동선으로 교체했다. 아래 같은 원화·동일 좌표 재사용은 당시 이력이다.

부모 승인 범위는 첫 제작 월드 하나다. AI 입문5장소를 없애지 않고, 기존 배경·마커·캐릭터·지도 스타일로 별도 세 지점을 연결한다. 새 아트·외부 생성·별도 저장을 추가하지 않는다.

| 학습 지점          | 기존 실제 활동                                          | 다음 지점의 조건                |
| ------------------ | ------------------------------------------------------- | ------------------------------- |
| 기획과 자료 정하기 | 제목·읽을 사람·목적·소개·실제 소개할 내용 입력          | 다섯 기획 항목이 비어 있지 않음 |
| 제작 요청 다듬기   | 같은 기획의 index.html 요청 생성·편집, 컴퓨터/예시 선택 | 요청과 선택한 방식이 있음       |
| 첫 화면 확인하기   | 제목·목록·버튼 확인, 관찰과 본인 실습/예시 기록         | 기존 단원의 확인 조건으로 완료  |

자료 수집이라는 이름으로 별도의 장식 활동이나 파일 업로드를 추가하지 않는다. 첫 지점의 실제 소개할 내용이 자료다. 지도 지점을 한 번 누르면 해당 단계가 바로 열린다. 완료하지 않은 지점도 필요한 선행 입력이 있으면 열 수 있다. 지도 클릭 횟수는 완료 조건이 아니다.

`WorkbookProgressContext`의 mapWorld와 projectStop이 선택 지도와 첫 제작 위치를 보관한다. AI 입문의 currentStop은 그대로 유지한다. 첫 제작의 수업 단계와 지도 위치가 같은 상태를 사용하므로 이전 설명·다음 설명·취소·이야기·라우트 왕복에서 서로 다르게 남지 않는다. 기존 전체 단원 시작/다시보기는 기획 단계부터 열고 지도 마커는 선택한 단계로 연다. 회원 서버 저장/localStorage는 추가하지 않는다.

첫 제작 지도와 AI 입문 지도는 지도 선택 버튼으로 왕복한다. 후속 화면/데이터/공개 최소 단원과 기존 기록은 공통 기록 영역을 재사용한다. 첫 제작 월드의 예시 완료는 실제 파일 제작 성공 인증과 구분한다. 나머지 독립 월드와 선택 AI 심화는 이번 작업으로 확대하지 않는다.

공통 패턴은 지도 식별자·월드별 현재 지점·기존 수업 단계 연결·입력 기반 선행 조건·완료/본인 적용 분리다. 새 월드의 실제 활동과 완료 기준을 먼저 대조한 뒤 같은 패턴을 적용할 수 있다. 이번 지도는 기존 AI 배경의 지형을 재사용하므로 서로 다른 월드만의 미술·분위기 판단은 남는다.

## 당시 미감 판단과 승인 경계 — 직접 승인 전 이력

원화의 위쪽 두 건물은 학습 마커가 없다. 기존 배경 재사용을 승인한 이번 세 지점 지도이며 새 그림을 만들지 않았다. 현재 캐릭터의 접지선이 현재 마커의 체크 표시 일부와 겹친다. 현재 위치·아래 완료 문구·활동 목록·접근성 상태는 확인되지만 작은 아이콘의 읽기는 보정 여지가 있다. 캐릭터 위치를 간격 토큰만큼 올리는 대안만 관찰했고 실행하지 않았다.

조율자의 자동 승인 검토가 ‘가림 최소보정·추가검수’를 최신의 수정/추가검사 없는 기록 마감 범위를 변경한다는 이유로 거절했다고 전달받았다. 우회·새 실행 없이 한계를 기록하고 마감했다. 보정은 별도 승인 범위다.

기능적으로 연결한 첫 제작 세 지점 단위의 완료이지 첫 월드의 모든 상세 학습 내용이나 전체4+1 클래스 완성이 아니다. 기본 잔여는 나머지3월드의 독립 지도·학습 지점 및 각 최소 단원을 확정 학습 결과에 맞춰 보강하는 작업이다. 실제 OS별 준비·외부 파일·공개 접속 증빙은 학습자 작업으로 남는다. 선택 AI 심화는 기본 완료 조건과 구분한다.
