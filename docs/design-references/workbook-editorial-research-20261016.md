## 이번 적용

‘화면으로 질문하기’ 한 편만 우선 새 펼침면으로 편집했다. ‘어디가 / 이상한가요?’를 짧은 시각적 제목으로 쓰고 기존 글 제목·요약·테스트 표시·메타데이터는 유지했다. 사진은 기존 생성 자산을 세로로 크롭한다. 왼쪽 고정 목차는 접힌 작은 목차로 바꾸고, 큰 도입 → 좁은 읽기 열 → 손 클로즈업+큰 요청 인용 → 읽기 열로 연결한다. 다른4편에 일괄 적용하지 않는다.

홈은 기존 소개와 추천 글을 같은 히어로의 수동 선택2개로 통합했다. 기존 대표 이미지와 추천글사진을 유지하고 별도 아래 홍보배너는 제거했다. 자동회전·추가모션은 없다.
