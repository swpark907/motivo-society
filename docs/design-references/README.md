## Workbook 컨셉 (`ref-workbook-concept-capybara.png`)

Workbook 페이지의 **적극적 레퍼런스**. 이미 컨셉이 담긴 목업이라 구조·정서를 모두 가져온다.

**구조 (레이아웃)**

- 좌측 레일: 로고 + "PLAY. LEARN. GROW." + 메뉴(Home · My Workbook · Missions · Library · Community · Tools · My Page) + 하단 Focus Mode(로파이 플레이어) + 손글씨 낙서
- 상단 히어로: 캐릭터 사진 위 `WORKBOOK` 라벨 + 큰 카피("지금의 내가, 더 멋진 나로.") + 한 줄 부제. 우상단 검색 · **연속 학습 N일 🔥** 스트릭 배지 · 프로필(이름 + **Lv.**)
- 본문 1열: **이번 주 미션** 4카드 (번호 · 제목 · 설명 · 이미지 · 진행률 바 % · 완료 체크) + 날짜 범위 네비
- 본문 2열: **카테고리별 워크북** 5카드 (Self · Work · Skill · Life · Creative — 영문 제목 + 한글 부제 + 이미지)
- 우측 컬럼: 인용구 카드 → 월 캘린더(활동일 오렌지 점) → **오늘의 체크리스트** N/M (+ 추가)

**정서 (톤)**

- 따뜻한 저녁 빛, 아늑함, 카피바라가 "나"의 아바타처럼 등장 (선글라스·후디·머그). 손글씨 문구("오늘도, 조금 더 멋진 나.", "Same Capybara Bigger You")
- 카드가 **라운드(≈12px)** 이고 사진 톤이 따뜻한 오렌지 — 전역 디자인 규칙(radius 2px · 날카롭게)과 다르다. → Workbook을 예외 스코프로 둘지, 전역 규칙을 조정할지 **미결** (AGENTS.md TODO)
- 브랜드 동물(카피바라)이 실사 톤 렌더로 쓰인 예 — "사진 톤을 따르는 일러스트" 규칙의 기준 이미지
