# 플랫폼 서비스 기준 시안 (L01b) — 2026-11-06

승우 피드백("전혀 서비스적인 디자인이라고 볼 수 없다")을 받고, 루프를 멈춘 뒤 먼저 만든 시안이다. 아직 승인되지 않았다.

- 화면: `/demo/design-platform/explore` · `/activity` · `/home` (개발 환경에서만 열림, 고정 예시 데이터)
- 코드: `src/app/demo/design-platform/`

## 원칙

- **이미지가 먼저.** 카드는 4:3 표지 사진, 상세는 16:10 히어로.
- **색은 종류 태그에만.** 모임 노랑 · 시즌 하늘 · 챌린지 초록 · 클럽 분홍(시안 값).
- **오렌지는 한 화면에 행동 하나.** 상세의 "신청하기", 홈의 "참가 정보 보기".
- **날짜와 사람이 먼저 보인다.** 카드: 언제 → 제목 → 장소·주최 → 얼굴과 남은 자리 · 가격.
- 모바일 상세는 하단 탭 바 위에 신청 바를 고정한다.
