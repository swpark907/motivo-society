## 새로 넣은 모티프

- **티켓**: 오늘 일정 한 장. 절취선과 반원 홈, `ADMIT ONE · 확정`, 큰 시각.
- **도장판**: 챌린지 인증. 찍은 날은 오렌지 원 도장.
- **테이프 붙인 사진**: 활동 상세 표지.
- **회차 카드**: 끝난 회차에 "끝남" 도장.
- **카피바라 말풍선**: 화면마다 한 번. 실제 규칙(중간 합류 등)만 말한다.
- **장부형 목록**: 둘러보기의 "그다음 일정". 위 묶음에 나온 활동을 다시 보여 주지 않는다(지금 화면의 중복 해소).

## 채택하려면 정할 것

1. 브랜드 규칙과의 충돌: "그림자 없음"(오프셋 그림자), "그라디언트 없음"(도트 그리드 무늬), 플랫폼 제품 화면 예외(파스텔·라운드 12~16px)를 이 방향으로 바꿀지. 예외는 아직 대표 확인 대기다.
2. 오렌지 `#ff4f1f`(임시) → `#ff751f`(motivo.kr 운영 중), 서체 Anton·Pretendard → Syne·시스템 고딕을 맞출지.
3. 상단 GNB도 motivo.kr처럼 흰 바탕 + 검은 선으로 바꿀지(시안에서는 기존 GNB 유지).
4. 표지 사진: 지금은 연출용 카피바라 생성 이미지. 실제 운영에서는 호스트·현장 사진(대표 랜딩 방식)으로.
