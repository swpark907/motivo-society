## 문법

- **머리 = 거대한 글자.** "FRI 13 / 할 일 2개", "둘러보기"를 Anton · Black Han Sans로 화면 폭만큼.
- **한 화면의 오렌지 순간 하나.** 홈은 오늘 밤 시각 `19:30`, 활동 상세는 신청 버튼.
- **사진은 흑백.** 카드에 마우스를 올리면 원래 색으로 돌아온다(120ms).
- **포스터 카드.** 4:5 사진 아래에 검은 띠를 깔고 큰 날짜(11.15 · TONIGHT).
- **기록표.** 그다음 일정은 경주 기록표처럼 큰 날짜 열 + 굵은 선. 회차는 앨범 트랙 목록.
- **긴 글은 종이.** 활동 소개만 따뜻한 흰 면 위에서 읽는다(브랜드 규칙 "읽기 표면은 종이").
- 카피바라 말풍선은 넣지 않았다. 사람(호스트·참가자의 한마디)이 앞에 선다.

## 두 시안 비교

|                | 작업 노트                                  | 포스터                                          |
| -------------- | ------------------------------------------ | ----------------------------------------------- |
| 뿌리           | 대표의 motivo.kr(랜딩 + 회원 공간)         | AGENTS.md 브랜드 규칙(AIR UK · Nike Run)        |
| 바탕           | 도트 그리드 종이                           | 검정                                            |
| 개성이 사는 곳 | 물건(티켓 · 도장판 · 테이프 사진 · 말풍선) | 글자 크기와 흑백 사진                           |
| 브랜드 규칙    | 그림자 · 무늬 예외가 필요                  | 그대로 지킨다. 예외 불필요                      |
| 매일 쓰기      | 밝아서 오래 봐도 편하다                    | 어둡고 강해서 피로할 수 있다                    |
| 대표 톤과      | 거의 같다                                  | 랜딩 히어로와만 닮았다                          |
| 위험           | 장식이 늘어나면 유아적으로 보일 수 있다    | 사진이 약하면(지금처럼 생성 이미지) 비어 보인다 |

두 안을 섞는 것도 가능하다: 머리 띠와 숫자는 포스터, 목록·카드 영역은 작업 노트의 종이.
