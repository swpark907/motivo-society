# 워크북 첫 정보성 글 5편 · 발행 전 검토

2026-10-16. 사용자 요청: AI 활용 전반과 웹·앱 제작 팁을 다양하게 섞는다. 기존 히어로 이미지는 유지하며 홍보용 대표 영역으로 사용한다.

## 현재 상태

5편 모두 **정식 미발행·테스트용 임시 공개 초안**이다. 에이전트가 공식 근거를 열어 참고했으나 사람의 실사용 검증은 하지 않았다. `publishedAt`·`verifiedAt`을 만들지 않았다. 사용자 후속 승인으로 별도 로더가 `/workbook/reading/[slug]` 테스트 프리뷰에서 읽으며 홈 홍보/읽을거리에도 연결한다. 테스트 글·검증 전 표시와 noindex를 제공한다. `content/articles`의 정식 검증 스키마는 변경하지 않는다. 초안 예문을 실제 성공 사례로 표현하지 않는다.

도구·버전/모델·환경·검증자·확인 날짜·관찰 결과를 해당 글의 검토 메모에 남긴다. 특정 도구의 API 문서에서 읽은 기능을 모든 소비자 앱에서 사용할 수 있다고 확대하지 않는다. 모든 제품에서 더 좋은 결과가 나온다는 약속은 하지 않는다.

## 검증 후 발행

1. 주제와 문구를 검토하고 사용할 도구에서 사람이 직접 확인한다.
2. 필요하면 초안을 고치고 실제 관찰과 설명용 예문을 구분한다.
3. `정식 Article 파이프라인에 이관하며 실제 `publishedAt`·`verifiedAt`을 적는다. 문서 메타데이터와 블록을 정식 렌더러가 지원하는지 함께 확인한다. 근거 `sources`를 유지한다.
4. `pnpm check`와 코드 리뷰 후 합의된 방식으로 발행한다. 영구 URL은 `/article/<slug>`다.

## 홈 연결 방향

- 기존 작업실 카피바라 이미지를 기본 히어로로 유지한다.
- 현재는 실제 이용 가능한 웹페이지 클래스를 홍보한다. 미발행 글로 연결하거나 예정 클래스를 열린 것처럼 홍보하지 않는다.
- 글 검증 후에는 클래스·팁·제작 사례 중 시점에 맞는 한 가지를 홍보하는 편집 자리로 사용한다. 배너 자동 순환은 추가하지 않는다.
- 첫 추천 후보는 ‘설명하기 어렵다면, 화면을 보여주고 한 곳을 짚어보세요’. 공개 시에는 익명화한 실제 화면/질문 사례를 확보해 기존 히어로 바로 아래의 작은 발견 영역에서 보여준다. 없는 전후 비교를 생성해 실험 결과로 쓰지 않는다.
- 아래 읽을거리는 검증된 첫5편으로 채우고 기존 미발행 가상 칼럼 카드는 대체한다. 사용자 후속 승인으로 임시 글5편의 프리뷰 링크로 교체했다.

원래의 대표 이미지 보존과 클래스 탐색 캐러셀·목록 페이지는 유지한다. 이번 작업은 콘텐츠 초안·홍보 배치의 검토 준비이며 새 이벤트·가격·출시 일정·영상 제작을 확정하지 않는다.

## 프론트 임시 공개 후속 승인

사용자가 테스트용 임시 발행과 아티클/홍보 디자인 진행을 직접 승인했다.5편은 테스트배지를 갖춘 별도워크북프리뷰이며 인간검증/정식발행 완료가 아니다. 썸네일/공식문서의 기능을 실험결과로 표현하지 않는다.

## 에디토리얼 문서 v1

현재 정본은 다섯 JSON 문서다. 기존 MDX의 내용과 근거를 보존해 구조화된 블록으로 이관했다. [편집 가이드](../../../docs/product/workbook-reading-authoring.md)와 [JSON Schema](../../schemas/workbook-editorial-v1.schema.json)를 함께 사용한다. 임의 코드를 실행하지 않으며 표지·폭·사진·분할·인용·비교·목록 배치를 선택한다. 짧은 글의 TOC는 생략하고 긴 guide에만 제공한다. 테스트 프리뷰와 정식 발행은 구분한다.
